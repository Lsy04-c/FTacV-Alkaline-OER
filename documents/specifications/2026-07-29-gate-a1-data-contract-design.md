# Gate A1 实验数据与采样契约设计

## 1. 目标

为四份 FTacV 实验文件建立不可歧义、可复算的数据入口。Gate A1 只回答：

1. 文件内容是否与冻结版本一致；
2. 三列数据如何解释；
3. 时间轴、采样、扫描和激励参数是否满足下游算法前提；
4. 哪些字段来自文件、计算推断或外部声明；
5. 数据能否进入后续反演。

Gate A1 不评价谐波质量、模型拟合、参数可识别性或实验重复性。

## 2. 范围

正式输入固定为：

| 数据集 | 文件 | 当前 SHA-256 |
|---|---|---|
| FT2 | `data/raw/ftacv2-ref-5hz.txt` | `979fdd7e132f8dffbe32671a9f3476eac4dcdcd79bc6ab8b29578af2401b0091` |
| FT3 | `data/raw/ftacv3-ref-5Hz.txt` | `72af2050d2b8400d68520df7aba5c08c74420b1b711c0e8f229fa64cdfaa468c` |
| FT4 | `data/raw/ftacv4-ref-1hz.txt` | `f9b6b8448dc27ed7a78147beb9b6b05aa2cba105d195cb6aaa30e473ffcb3a21` |
| FT8 | `data/raw/ftacv8-ref-5Hz.txt` | `943d2406370be468c4a112a337c55d53ef16c43482b610915ca552723ae9be0d` |

每份文件当前有 65,535 行。原始文件只读；Gate 不生成覆盖原文件的
“清洗版”。

CV 文件、仪器方法文件和真实反演不属于本阶段。

## 3. 证据等级

每个元数据字段必须带 `source_kind`：

| 等级 | 含义 | 可否单独支持 Gate PASS |
|---|---|---|
| `file_observed` | 文件字节或数值列直接给出 | 可以 |
| `derived` | 由冻结算法从原始列计算 | 可以，但必须保存方法与误差 |
| `externally_declared` | 仪器方法、实验记录或负责人明确声明 | 可以，必须记录来源 |
| `legacy_assumption` | 仅来自旧代码、文件名或历史默认值 | 不可以 |
| `unresolved` | 无可靠来源 | 不可以 |

文件名中的 `5hz` 或 `1hz` 只能用于交叉检查，不能作为基频真值。旧代码中的
`E_start`、`E_end`、`f`、`dE` 和单位默认值不能反向证明实验元数据。

## 4. 冻结 schema

每份文件必须解析为三列：

```text
potential | current | time
```

每列契约：

| 字段 | 数据要求 | 单位要求 |
|---|---|---|
| `potential` | float64、有限值 | 电位标尺与单位必须有外部声明 |
| `current` | float64、有限值 | A 或其他原始单位必须有外部声明 |
| `time` | float64、有限、严格递增 | 秒或其他原始单位必须有外部声明 |

解析器拒绝：

- 少于或多于三列；
- 空文件、非数值行、NaN 或 Inf；
- 重复、倒序或非正时间增量；
- 隐式丢弃表头、尾行或额外列；
- 未声明的电位参考修正；
- 未记录的排序、去重、裁剪或插值。

旧 `io.py` 的“只取前三列、排序、去重”行为不能用于 Gate A1 正式入口，
因为它会把格式错误转化为看似可用的数据。

## 5. 派生采样指标

对原始顺序计算：

- `n_rows`、文件字节数和 SHA-256；
- `time_start`、`time_end`、duration；
- `dt_min`、`dt_median`、`dt_max`；
- 采样率 `fs = 1 / median(dt)`；
- 抖动：
  `max(abs(dt - median(dt))) / median(dt)`；
- 缺口：
  `max(dt) / median(dt)`；
- 电位线性趋势、交流残差和残差主频；
- 交流振幅；
- 趋势起点、终点和扫描速率；
- 整周期数、首尾非整周期余量。

主频只从应用电位残差推断。电流频谱只作交叉检查，不能定义激励频率。

## 6. 数值门

以下阈值在查看正式派生结果前冻结：

- 三列且恰好 65,535 行；
- 所有值有限；
- 时间严格递增；
- `dt_median > 0`；
- 采样抖动 `<= 1e-3`；
- 最大采样缺口 `<= 1.01 × dt_median`；
- 基频必须是正有限值；
- 每周期采样点 `fs / f0 >= 64`；
- 至少包含 20 个完整激励周期；
- 电位残差主峰与声明基频相对误差 `<= 1e-3`；
- 声明与推断扫描速率相对误差 `<= 5e-4`；
- 声明与推断交流振幅相对误差 `<= 5e-3`。

阈值若因真实仪器量化或导出格式不适用，Gate 先 FAIL。后续只能提交带
独立依据的新版本协议，不能在同一次正式验收中调整。

## 7. 元数据门

下列字段必须为 `file_observed`、`derived` 或 `externally_declared`：

- 三列的名称和单位；
- 电位参考标尺；
- 基频；
-交流振幅；
- 扫描方向和扫描速率；
- 数据是否为一次连续正扫；
- 是否在导出前做过仪器侧滤波、平均、裁剪或背景扣除。

如果当前仓库无法提供单位、电位参考或仪器预处理来源，正式结论必须是
`FAIL_METADATA`。代码和数值入口仍可完成，但不能把历史惯例升级为事实。

## 8. 组件边界

### 8.1 严格解析器

放入 `oer_aem.data_contract`。输入为路径，输出不可变的
`ExperimentalTrace` 与解析事实。它不排序、不去重、不插值、不修改单位。

### 8.2 数据集注册表

建立受版本控制的 YAML 或 JSON 文件。每项包含：

- dataset id 和相对路径；
- 预期 SHA-256、字节数、行列数；
- 列名、单位及来源等级；
- 外部声明的激励和扫描元数据；
- 允许的下游用途；
- 来源说明。

注册表不得包含绝对本机路径或凭据。

### 8.3 审计器

独立读取注册表和原始文件，重算所有事实与派生指标，输出：

- `dataset_contracts.json`：逐数据集完整证据；
- `gate_a1_summary.json`：总门和失败分类；
- `acceptance.md`：允许与禁止的项目结论。

审计器不调用 Web 后端的 `_analyze_ftacv_data`，避免把应用层启发式当成
底层契约。

### 8.4 下游适配

Gate PASS 后，现有 `io.py` 通过严格解析结果进入显式预处理函数。排序、
裁剪、重采样和插值必须分别产生 provenance；正式入口不再静默执行。

## 9. 失败分类与退出

| 分类 | 条件 | 后续 |
|---|---|---|
| `FAIL_STRUCTURE` | 文件、哈希、行列或解析失败 | 停止全部下游步骤 |
| `FAIL_NUMERICAL` | 非有限值、时间轴或采样门失败 | 停止，不修补原始数据 |
| `FAIL_METADATA` | 单位、参考标尺或处理历史无可靠来源 | 保留证据，等待外部声明 |
| `PASS` | 四份数据结构、数值和元数据全部通过 | 冻结 Gate A1 |

单个数据集失败时，总 Gate FAIL。审计同时报告其他数据集结果，但不得用
三份通过替代四份契约。

## 10. 测试设计

### 单元测试

- 正确三列文件保持原始顺序和数值；
- 四列、两列、表头、空行、非数值和非有限值均拒绝；
- 倒序或重复时间拒绝，不自动排序或去重；
- 文件内容改变一字节即触发哈希失败；
- 元数据来源等级参与 Gate 判定；
- 派生频率、振幅、扫描速率在合成信号上满足已知真值；
- 每个阈值测试边界值和刚越界值。

### 集成测试

- 四份真实文件生成固定 schema；
- 重跑输出在同一代码、注册表和原始文件下逐字节一致；
- 从不同工作目录运行不改变路径解析；
- 审计器独立于 Web、绘图库和 C++ 动态库；
- 修改注册表或原始文件后 resume/复用被拒绝。

### 压力测试

- 把 filename 中频率改错，审计仍以电位推断和外部声明为准；
- 把时间列整体平移，派生 duration 和采样率不变；
- 删除中间一行，缺口门必须失败；
- 交换两行，时间单调门必须失败；
- 添加第四列，结构门必须失败；
- 只提供旧代码默认单位，元数据门必须失败。

## 11. 完成标准

Gate A1 只有在以下证据同时存在时才可关闭：

1. 严格解析器和注册表已实现；
2. 单元与集成测试通过；
3. 四份原始文件哈希与当前冻结值一致；
4. 正式审计输出 schema 完整且有限；
5. 每个关键元数据具有可接受的来源等级；
6. 独立 validator 重算结果一致；
7. 正式证据、项目进度和纠错记录已提交并推送。

如果仅缺外部元数据，阶段交付为“工程实现完成，Gate A1
`FAIL_METADATA`”，不得写成 PASS。

## 12. 设计压力测试结论

- **数据泄漏：** 本 Gate 不使用模型拟合结果或参数真值。
- **事后阈值：** 数值阈值在正式审计前冻结。
- **静默修复：** 解析器禁止排序、去重、裁剪和插值。
- **来源混淆：** 文件事实、推断值、外部声明和历史假设分层保存。
- **环境依赖：** 审计只依赖 Python/NumPy，不依赖 CN、LSODA、Web 或
  Legion。
- **失败退出：** 任一数据集或关键元数据失败即停止 A1 下游集成。
- **当前最大风险：** 仓库尚未看到电位参考、三列单位和仪器侧预处理的
  一手记录；因此 A1 很可能先得到 `FAIL_METADATA`。这是可信失败，不应
  用文件名或旧默认值补齐。
