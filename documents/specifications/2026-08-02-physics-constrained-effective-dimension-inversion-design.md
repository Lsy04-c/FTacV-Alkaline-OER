# OER-FTAcV 物理约束有效维数反演优化方案

状态：甲方已批准启动；G1开发切片已实现，G2/G3算法核心已启动，正式Gate未通过
日期：2026-08-02
范围：算法、物理、数值和验证架构；不修改当前冻结的 A6-v2 S1

网络审计：`documents/research/2026-08-02-network-literature-physical-pressure-test.md`
G1实施计划：`documents/plans/2026-08-02-g1-effective-electrode-scale-implementation.md`

## 1. 目标

建立一条同时满足物理合理性、参数可辨识性、计算可承受性和科研可审计性的
OER-FTAcV 反演路线。算法面向版本化的 `N` 维参数集合；当前 M0 登记13个
参数，但更换机理、背景模型或外部固定输入后 `N` 可以改变。目标不是让曲线
尽可能好看，也不是预先指定参数组数或有效维数，而是回答：

1. 当前数据能够识别哪些单参数或参数组合；
2. 哪些参数只能依靠外部测量、先验范围或不确定度传播；
3. 哪些物理约束必须硬执行，哪些只能作为有来源的软先验；
4. 如何减少昂贵 LSODA 正演次数，同时保留多盆地证据；
5. 何时允许从条件模型分析升级为正式真实数据反演。

## 2. 当前证据边界

- A2-R 已证明冻结12个合成案例内的覆盖度、守恒、电流闭合、稳态和求解器
  回退契约成立；它不证明整个参数空间稳定，也不证明五步 M0 是真实机理。
- A3 已证明现有 C++ CN 在锁相相位上不等价，不能承担正式结论。
- A5 已冻结候选不变的 `hybrid` H1–H3 特征契约和128点特征网格。
- A6 当前是 `FAIL_RECOVERY`：13个登记参数中8个为运行时固定、5个为
  `diagnostic_only`，没有具备真实数据正式反演资格的自由参数。
- 当前 A6-v2 S1 只检验三个两参数组合在 P0/P1/P2 合成协议下的条件恢复；
  其他参数取准确合成真值，因此不能代表当前 M0 全参数联合反演。
- A1 仍缺少完整一手实验元数据。现有真实数据只能承担条件分析，不能用界面
  或优化器升级绕过该限制。

## 3. 路线比较

| 路线 | 优点 | 主要失败模式 | 决策 |
|---|---|---|---|
| 仅替换 TPE | 改动小，可直接比较 CMA-ES/DE | 不解决物理失真、有效维数、单次正演成本和多解 | 仅作基准 |
| 预设物理分组后分块优化 | 易解释，单次子问题维数低 | 不是真降维；顺序依赖；漏掉跨组补偿 | 保留为对照 |
| 物理约束 + 有效组合 + 混合优化 | 同时处理可辨识性、物理和计算 | 设计与验证成本较高 | 推荐主线 |

推荐路线不预设参数组数或最终有效维数；两者均由解析结构、版本化参数集合和
留出验证证据决定。解析等价参数必须先合并，不能交给敏感性算法“自动发现”。

## 4. 总体架构

```text
实验数据与协议契约
        ↓
解析物理结构与参数本体
        ↓
物理模型与硬不变量
        ↓
正式数值后端与失败记录
        ↓
冻结特征和噪声模型
        ↓
模型充分性与噪声契约
        ↓
多锚点敏感性与交互张量
        ↓
有效参数组合 / 物理分组解释
        ↓
全局多盆地搜索 + 局部精修
        ↓
正式恢复 / 跨模型失配 / 不确定度
        ↓
正式证据或受限结论
```

每层只通过版本化输入、输出和 validator 与下一层通信。下游优化成功不能覆盖
上游物理、数据或求解器 Gate 的失败。

## 5. 物理合理性层

### 5.1 三类约束

物理条件必须按证据强度分为三类，不得全部写成任意惩罚项。

| 类型 | 示例 | 执行方式 |
|---|---|---|
| 硬不变量 | 有限值、覆盖度和、覆盖度边界、电流闭合、冻结热力学闭合 | 违反即拒绝候选并记录失败原因 |
| 有来源的先验 | `Ru/Cdl/gamma/A` 的独立测量范围、文献范围 | 概率先验或冻结边界，传播不确定度 |
| 模型充分性诊断 | 电位分区残差、谐波结构残差、协议间系统偏差 | 触发模型审查，不用参数惩罚掩盖 |

硬约束只包含已经由模型定义或独立物理定律支持的条件。未验证的机理偏好不能
伪装成硬约束。

### 5.2 候选级物理检查

每次正演至少返回：

- 求解器 attempt、成功状态和有限值；
- 覆盖度最小值、最大值与总和误差；
- 最终周期或终态 RHS 范数；
- 各法拉第/电容电流分量和总电流闭合误差；
- 冻结热力学契约检查；
- 参数是否触碰边界及其来源。

可以在求解前检查的代数约束应提前执行，避免为明显不合法候选支付 ODE 成本。
求解后失败必须分类为物理、数值或基础设施失败，不能统一写成大罚值后丢失
原因。

### 5.3 机理充分性

参数优化只回答“冻结 M0 在给定条件下能否解释数据”。出现以下模式时，应优先
审查机理、背景或实验条件，而不是继续增加优化预算：

- 不同协议在相同电位区出现同方向系统残差；
- DC 可拟合但 H1–H3 的幅值或相位残差保持结构化；
- 最优解持续依赖边界或固定输入极值；
- 不同数据集要求互相冲突的参数组合；
- 合成恢复通过但真实数据的残差远高于噪声代理。

可能的背景、传质、气泡、表面重构和预氧化残余只作为待验证解释。没有实验
对照或独立门时，不直接扩展机理。

### 5.4 当前 M0 的解释边界

当前五步M0是固定条件下的有效微观动力学假设，不是Bonke 2016“分子催化”
模型的直接复现。实施前必须在schema中冻结或登记：

- 温度、pH、支持电解质、OH活度代理、水活度、氧活度/气氛和标准态；
- 电位标尺与RHE换算、扫描历史和初始状态规则；
- 共享转移系数 `a=0.5`、常数 `Cdl`、固定 `gamma` 的模型假设身份；
- `k0_pre/k0_1...k0_4` 是当前条件下的有效速率，不是已验证的材料微观常数。

RHE标尺可吸收理想质子化学势的部分pH依赖，但不能替代反应级数、局部OH活度、
氧活度和电双层效应。跨pH、浓度或气氛比较前，必须升级活度模型并独立过门。

## 6. 参数坐标、角色和物理分组

### 6.1 先消除解析结构不辨识

当前M0满足：

```text
dφ/dt = (Eapp-φ)/(Ru·Cdl·A) - (gamma·F/Cdl) Σrj
i      = (Eapp-φ)/Ru
```

对任意正数 `c`，变换 `A'=cA, Cdl'=Cdl/c, gamma'=gamma/c` 保持整个状态轨迹
和总电流不变。因此 `A/Cdl/gamma` 不能由当前总电流分别识别。正式新schema在
观测为总电流A时应使用：

```text
CdlA   = A·Cdl       # 总双电层电容，F
GammaA = A·gamma     # 总活性位点量，mol
Ru
```

`A`只有在独立测量后才用于将总量换算为面密度；它不再与 `Cdl/gamma`同时作为
正演自由参数。若实验数据已经归一为电流密度，schema应直接使用面`Cdl/gamma`，
`A`退出正演。现有A1已将电流单位`A`登记为用户声明，配套CHI CV文件头提供
辅助证据，因此条件分支可冻结`current_basis=total`；原始预处理、仪器增益和
面积归一化历史仍未闭合。该等价变换必须先有全轨迹、DC、H1-H3和派生电流
分量的自动测试。合成开发与条件模型可先实施`CdlA/GammaA`，但A1保持
`FAIL_METADATA`时禁止正式真实参数解释。只要对应分支的口径未冻结或测试未
固化，G1不得通过。

### 6.2 参数角色优先于优化分组

任何模型版本先从机器可读 parameter schema 读取参数集合，不在算法中硬编码
数量或名称。每个参数记录模型版本、物理含义、单位、变换、边界、来源、角色
和不确定度。参数增删或定义变化必须生成新 schema 版本和参数映射，不能把旧
优化结果直接混入新模型。

旧M0的13个登记参数只描述当前实现，重参数化后的自由维数必须由新schema重新
计算，不沿用“13维”标签。参数先按推断角色处理：

| 角色 | 参数 | 新方案中的处理 |
|---|---|---|
| 外部/校准输入 | `CdlA,Ru,E0_pre,k0_pre` | 以测量范围或压力场景传播，不默认自由优化 |
| 报告换算输入 | `A` | 只将`CdlA/GammaA`换算为面密度并传播误差 |
| 耦合控制 | `GammaA,scaling_OOH_OH` | 重新评估组合方向，不把当前固定值当精确真值 |
| 低敏感固定 | `k0_4` | 在新协议下复核敏感性；未提高前保持固定 |
| 诊断参数 | `k0_1,k0_2,k0_3,G_OH,G_O` | 进入有效组合发现，不自动获得点估计资格 |

### 6.3 无量纲编码

- 严格为正且跨数量级的速率、标度参数使用 `log10` 坐标；
- 能量和标准电位在有物理来源的边界内线性编码；
- 所有编码坐标最终映射到统一有限区间；
- 边界、单位、变换、来源和版本写入机器可读 parameter schema；
- 归一化只解决数值尺度，不等于解决可辨识性。

### 6.4 候选物理块

以下只作为解释和对照，不作为预设结果：

1. 总量标度：`GammaA`；
2. 电学背景：`CdlA,Ru`；
3. 预氧化：`E0_pre,k0_pre`；
4. OER动力学：`k0_1,k0_2,k0_3,k0_4`；
5. OER热力学：`G_OH,G_O,scaling_OOH_OH`。

若数据支持跨块组合，例如 `GammaA` 与某个 `k0` 的补偿方向，算法必须保留该
方向，不能为了得到整齐分组而切断。

## 7. 有效维数发现

本节只作用于已经通过G1解析重参数化的独立坐标。对含精确冗余的原始
`A/Cdl/gamma`坐标计算Gramian，会产生必然的零方向并污染数值条件数，不能
称为数据驱动发现。

### 7.1 噪声白化敏感性

在多个预注册参数锚点、P0/P1/P2 条件和可用特征上计算：

```text
J(k) = L⁻¹ ∂f(k)/∂x
```

其中 `x` 是无量纲参数，`f` 是冻结特征向量，`L Lᵀ` 是特征噪声或稳定性
协方差。没有可靠协方差时，先使用冻结稳定性尺度并明确其代理性质。

锚点必须在查看敏感性结果前由 Sobol 或现有 truth library 冻结。训练锚点、
维数选择锚点和留出验证锚点分开，防止用同一批结果选择并验证降维。

### 7.2 交互和补偿

同时记录：

- 参数列范数：在当前噪声下的影响强度；
- 有符号余弦相似度：同向/反向补偿；
- 多锚点稳定性：相关结构是否随参数区域改变；
- 混合差分或全局总效应：非线性交互；
- 不同协议对敏感方向的旋转：新增实验是否提供独立信息。

高影响不等于可辨识。两个高影响但高度共线的参数只能支持一个组合方向。

### 7.3 活跃组合

堆叠白化 Jacobian，构造信息矩阵：

```text
F = Σ J(k)ᵀ J(k)
```

本文将 `F` 称为白化敏感性 Gramian。只有锚点及其权重来自预先冻结的参数
分布时，它才可解释为 active-subspace 式梯度外积估计；只有残差噪声模型、
局部线性化和似然口径成立时，才可解释为 Gauss–Newton/Fisher 型信息近似。
这些名称不能互相替代。

通过 SVD/特征分解得到候选组合 `z = Wᵀx`。特征值谱可描述相对 stiff/sloppy
方向，但不能单独证明可辨识性。有效维数由留出条件决定：沿被丢弃方向变化时，
冻结特征的最坏偏差必须保持在预注册噪声门内；不能只用累计解释方差或事后
选择某个预设维数。

若活跃方向随参数区域强烈弯曲，线性子空间失败。此时采用分区局部子空间或
保留原分块，不升级到不可解释的神经网络编码。有效维数 `r` 只要求满足
`r ≤ N`，不要求对应某个预设组数。

2026-08-02已实现开发态算法核心：支持对角标准差或完整协方差白化、多锚点
正权聚合、白化Gramian特征分解和稳定特征向量符号。API故意不输出自动有效维数。
现有importance报告的列对不同原始单位/对数坐标求导，接入时必须显式提供到
`[0,1]`无量纲坐标的列尺度；缺失任一参数尺度即失败。旧hybrid矩阵仅作烟测：
单位归一化前后首方向从`Cdl`主导变为`Ru`主导，证明旧谱不具备新方案
的正式结论资格。

2026-08-02开发smoke补充结果：量化分辨率下限通过同标准差均匀误差传播到
冻结特征，仅形成对角稳定性尺度，不解释为重复实验协方差。lock-in插值有效
窗外的96行在所有信号下均由掩码固定为0，既无方差也无敏感性，已依据采集
几何而非参数结果从契约排除；保留134行。候选维数只由两个selection锚点的
最坏白化丢弃算子范数`<=1`产生。12、24和48个固定噪声seed均要求完整7维；
48-seed下r6仍为`712.16`。因此本轮结论是“当前冻结条件不支持线性降维”，
不是“发现六维”；holdout中r6低于1σ不得反向用于选维。

### 7.4 允许的科学输出

- 若只能恢复 `log(A·gamma)`，只报告该组合；
- 若某组有两个稳定方向，保留两个组合变量；
- 被丢弃方向只报告“当前条件下未分辨”，不得写成参数不存在或等于默认值；
- 只有组合展开后的单参数也通过独立恢复门，才允许报告单参数点估计。

### 7.5 实用可辨识性 profile 门

G3 冻结候选有效空间后，对以下对象执行 profile likelihood 或等价的冻结
似然 profile：

- 每个拟报告的活跃组合坐标；
- 每个试图从组合展开并单独报告的原始参数；
- 存在多盆地或边界依赖的关键方向。

profile 固定一个坐标并重新优化其余允许坐标，向两侧推进到边界或预注册阈值。
阈值必须来自明确的噪声/似然模型；若当前 objective 不能解释为负对数似然，
只能称 objective profile，不能借用似然置信区间。

profile 输出有限区间、单侧区间、边界未闭合或多峰。只有有限且在留出恢复中
稳定的区间支持点估计资格。inactive 方向不能简单钉在名义值并当作已知，应在
其先验/压力范围内 profile、边缘化或传播。考虑到计算成本，本门在降维后执行，
不要求先对全部 `N` 个原始坐标运行完整 profile。

## 8. 优化与推断

### 8.1 多盆地优先

优化器必须返回多个相互分离的候选盆地，而不是只返回一个最小值。每个盆地
保留参数、目标分量、物理状态、边界状态和 provenance。

### 8.2 按有效维数路由

| 有效维数 | 首选候选 |
|---:|---|
| 1–4 | 批量 Sobol/DIRECT探索 + 多起点 trust-region least-squares |
| 5–8 | Sobol/scatter初始点 + 多起点梯度局部法；再比较TuRBO/BIPOP-CMA-ES |
| 9以上 | 优先补实验/先验和求解器加速，不以小预算黑箱搜索宣称全局解 |

TPE保留为历史基线。可靠残差Jacobian或灵敏度可用时，多起点梯度法是默认
工程基线；TuRBO/CMA只在该基线漏盆地或不稳定时竞争默认资格。CMA-ES只在
全局固定调用预算、初始化不泄漏真值、同代
候选可并行且有 checkpoint 时进入比较；师兄 HER 中的100000次/重启配置不
进入 OER。

### 8.3 全局—局部流程

```text
物理可行域筛选
→ 批量全局探索
→ 聚类得到 K 个候选盆地
→ 每个盆地独立局部精修
→ 小预算跨组联合校正
→ profile / 后验 / 留出协议比较
```

局部阶段优先使用残差向量，而不是只接收标量总损失，以利用特征结构和有限差分
Jacobian。若局部算法与全局算法使用不同目标，必须显式登记，不能混称一次优化。

### 8.4 不确定度

正式点估计前至少区分：

- 优化 seed 和多盆地不确定度；
- 固定输入 `Ru/CdlA/GammaA` 的传播，以及`A`对面密度报告的换算误差；
- 实验噪声与批次变化；
- 求解器误差；
- 模型失配。

MCMC或其他后验方法只在已通过恢复门的低维组合空间内运行。后验变窄不能覆盖
错误模型或过强先验。

## 9. 计算性能优化

### 9.1 先测量再改写

对正式代表任务分别记录：

- ODE稳态初始化；
- 动态积分；
- 电流重建；
- FFT、complex harmonic、lock-in和插值；
- 条件聚合和优化器开销。

旧的50 ms/solve估算已不适用于当前32,768–65,536点正式配置。所有加速结论
必须以真实协议和相同输出契约测量。

### 9.2 无科学风险的优先项

1. 缓存实验目标、波形、滤波器、插值网格和不随候选变化的特征；
2. 同一候选的多条件结果按参数哈希复用；
3. 全局/种群候选批量并行，每个 worker 限制数值库线程；
4. 敏感性、代理模型和优化器共享已评估坐标，不重复正演；
5. 原子 checkpoint、断点恢复和取消语义保持不变。

### 9.3 新数值后端

前向灵敏度方程或CVODES状态—灵敏度联合原型优先于替换优化器，因为它同时
减少多参数中心差分和局部精修成本。CVODE/CVODES类编译刚性求解器、MATLAB
`ode15s` 或其他后端可以作为原型比较。周期稳态法暂不列为首选：当前协议含
持续DC斜坡，不是严格周期系统。任何后端必须重过：

- 状态和电流不变量；
- DC与H1–H3幅值、复相位和lock-in等价性；
- 极端参数成功率；
- 参数排序和候选盆地保持；
- 正式配置实际加速比。

现有CN失败证据保持，不通过调阈值重新启用。低精度筛选—LSODA确认只有在
筛选后端通过“不会漏掉正式候选盆地”的独立门后才允许。

粗后端若只用于估计活跃方向，也必须比较其与LSODA方向的主夹角、留出输出误差
和组合恢复；计算更快但方向不稳定时，不得进入降维或优化器初始化。

现有五个覆盖度受总和为1约束，实际只有四个独立覆盖度；RHS又在每次评价时
归一化覆盖度。灵敏度原型启动前，必须先比较“四独立状态重建第五状态”和
“五状态加显式守恒失败”两条路线。隐藏归一化不得直接进入正式灵敏度后端。

2026-08-02诊断结果：四坐标在内部物理状态与五状态的RHS一致；内部物理短轨迹中
最大覆盖度差`2.54e-9`、表面电位差`5.09e-10 V`、总电流差
`5.09e-11 A`。边界初值下LSODA会生成约`-9.26e-8`内部试探点；将“内部
严格守恒”与“输出点物理边界验收”分离后，边界四/五状态均成功，输出
最小覆盖度为0、守恒误差`2.22e-16`、总电流差`9.29e-11 A`。全过程未截断、
未归一化、未放宽物理门。更长协议和灵敏度方向等价性通过前，仍不切换正式路径。

### 9.4 产品性能目标

桌面端完整实施前，另行冻结交互性能门。当前建议值仅作待验证目标：数据分析

## 10. 数据和实验接口

休假期间不能补实验时：

- 使用现有四组数据做条件模型、残差和稳定性分析；
- 不把四组不同实验平均为重复实验；
- 不利用真实数据结果反向选择合成真值、参数边界或降维方向；
- 所有真实数据最优参数保持条件候选口径。

恢复实验后优先补：

- 一手仪器方法、RHE换算和预处理；
- `Ru/CdlA/A/GammaA`等独立约束及其误差；
- pH、支持电解质、浓度、气氛、温度和标准态；
- 空白基底、负载量和批次对照；
- V4建议的频率、振幅和扫描协议；
- 用于留出验证而非调参的独立条件。

实验设计的目标不是简单增加数据量，而是使敏感方向旋转、提高信息矩阵最小
有效特征值并降低参数补偿。

## 11. 分阶段 Gate

| Gate | 内容 | 通过信号 | 失败动作 |
|---|---|---|---|
| G0 | 当前A6-v2 S1 | 按冻结设计完成验收 | 保留结论，不回写本方案 |
| G1 | 解析结构与参数schema | 电流/面积口径闭合；精确等价变换已合并；参数定义、条件、来源和硬/软约束可机读且测试通过 | 停止下游 |
| G2 | 模型充分性与噪声 | 背景、初值、分通道残差和噪声代理已冻结；稳定失配未被参数边界吸收 | 停止降维 |
| G3 | 多锚点敏感性与组合 | 训练/留出拆分完整；丢弃方向低于冻结噪声门 | 保留更高维或原空间 |
| G4 | profile与低维恢复 | 活跃组合及拟报告单参数profile闭合，留出恢复通过 | 只报告组合或条件范围 |
| G5 | 优化器基准 | 在冻结 `z` 空间内，同调用和墙钟预算下恢复优于基线，失败率不增 | 保留旧基线，不追加预算 |
| G6 | 新后端等价性 | 物理、谐波、灵敏度、盆地和速度门全部通过 | 禁止承担正式结论 |
| G7 | 正式合成恢复 | 多真值、多seed、噪声、固定输入扰动和跨模型失配全部过门 | 禁止真实参数点估计 |
| G8 | 真实数据模型充分性 | 多协议残差无未解释系统结构，A1闭合 | 仅报告条件分析 |
| G9 | 不确定度与交付 | profile/后验/留出和本地远程一致性通过 | 不进入正式界面结论 |

G3、G5和G6是独立变量：降维、优化器和求解器不得在同一确认门中同时改变。

### 12.1 对推荐方案的攻击

### 12.2 停止条件

- 有效子空间在留出锚点或协议间不稳定；
- 丢弃方向引起超过噪声门的特征变化；
- 合成组合可恢复，但原参数展开不可恢复却仍要求点估计；
- 新优化器只降低最优损失，未改善恢复误差和seed稳定性；
- 新后端速度提高但谐波相位、盆地召回或物理不变量失败；
- 真实数据残差提示模型不足，却继续用参数边界吸收偏差；
- 计算目标达不到且没有新的可验证加速假设。

## 13. 实施顺序

### 阶段A：关闭当前证据

完成A6-v2 S1同步与独立验收。只回答冻结多协议、两参数、TPE、LSODA问题。

### 阶段B：低成本审计

1. 以A1用户声明和配套文件头冻结条件分支总电流口径，保留预处理缺口；
2. 为 `A/Cdl/gamma` 解析等价变换增加自动测试；
3. 建立以`CdlA/GammaA`为核心、不硬编码参数数量的机器可读schema；
4. 登记温度、pH、活度、气氛、标准态、初值和所有M0假设；
5. 诊断四/五覆盖度状态表示与隐藏归一化；
6. 为目标函数增加物理失败分类而非统一罚值；
7. 对正式代表任务做分段性能基准。

### 阶段C：模型充分性基线

1. 冻结背景、噪声、初始化和分通道残差契约；
2. 不增加自由参数，先比较现有四组数据中的稳定残差；
3. 一次只压力测试一个M0假设；
4. 只有跨数据/协议可复现的残差才注册新模型版本。

### 阶段D：有效维数实验

1. 冻结参数锚点、协议、特征和训练/留出拆分；
2. 小规模 smoke 后运行多锚点白化敏感性；
3. 比较物理分组、无分组活跃方向和不降维基线；
4. 只在留出输出误差和组合恢复通过后冻结降维版本；
5. 对活跃组合及拟展开单参数执行profile门。

当前开发状态：步骤1-3的最小smoke已完成，但selection门要求保留完整7维，
故步骤4未通过，步骤5及低维优化器路由暂停。下一次重开本阶段必须引入独立
信息变化（新协议、可信固定输入范围或分区局部子空间假设）并单独验收；禁止
仅提高优化预算或使用holdout结果事后降低维数。

扩展锚点诊断在查看新结果前冻结为：scrambled Sobol seed 23，12个training、
4个selection、2个holdout；参数、边界、256点LSODA、DC/complex H1-H3/
lock-in有效窗、量化噪声证据和48个噪声seed均保持不变。该诊断只回答局部
有效秩和主角随参数区域是否稳定，不自动选择分区数，也不进入优化器。若局部
低秩但全局方向在selection失效，只能登记“分区局部子空间候选”；分区规则
必须随后仅用training锚点冻结，并由selection选择、holdout最终验证。

扩展结果：18个锚点、270次敏感性正演均成功且无ODE失败。training局部有效
秩覆盖2–6，前1–6维相对全局基的最坏主角为约`54.67°–86.50°`；selection
局部秩为3–4但方向同样旋转，r6丢弃算子范数为`52063.81`；holdout r6最坏
偏差为`20.76σ`。因此单一全局线性子空间在当前参数域失败。当前不自动构造
分区，因为没有仅由training冻结并由selection通过的物理分区规则。G3失败
动作采用“保留原7维”；G4/G5后续只能在完整无量纲空间做开发恢复和固定预算
全局—局部基线，不能再把最低loss解释为降维成功。

完整7维最小优化smoke在运行前冻结为：`mixed_a`单一合成真值、零噪声、
LSODA 256点、hybrid DC/H1-H3、optimizer seed 23；TPE、64点Sobol+四盆地
坐标pattern、64点Sobol+两pattern/两Powell盆地各严格256次调用。该smoke
只允许淘汰明显不合格算法，不能选择默认算法或证明7参数可恢复。候选只有在
调用数精确、ODE/特征失败不增加、最大和中位无量纲恢复误差均优于TPE时，才
可进入多truth/multi-seed扩展；最低loss或单次更快不能单独晋级。

首轮若Sobol四盆地候选不能进入TPE所在盆地，只允许追加一个同预算诊断：
`192次TPE全局 + 64次有边界Powell`。它复用同一真值、seed、目标和256调用
总预算，检验“已有盆地缺少局部精修”这一单一假设；若仍不能同时改善最大和
中位恢复误差，停止本轮优化器组合搜索，不继续增加预算或算法名单。

执行结果：两种Sobol多盆地候选均未进入TPE盆地，最大误差为`0.6000`；
TPE基线最大/中位误差为`0.4266/0.1672`。TPE+Powell将loss由`2.8505`降到
`0.1481`，但最大误差仍为`0.4266`且中位误差变差到`0.1782`。因此所有
新增候选停止在开发态，G5未通过。该结果按设计解释为“目标补偿/信息与搜索
问题尚未分离”，不得追加CMA-ES、TuRBO或预算。下一门为同一真值点的白化
局部秩及objective profile；只有恢复误差门而非loss门允许重开优化器比较。

真值点诊断冻结为同一`mixed_a`、LSODA和特征契约：用量化分辨率下限及48个
固定seed计算局部白化奇异值，以`>1`仅报告一标准差局部有效秩；同时对每个
参数在真值±`0.05/0.10`无量纲坐标处计算条件objective切片，其余参数固定为
真值。该切片明确不是profile likelihood，因为未重优化补参数；它只定位局部
弱方向。若局部秩小于7，单参数全点恢复资格直接失败；即使等于7，仍需完整
objective profile和留出恢复，不能据条件切片宣布可辨识。

执行结果：局部奇异值末两项为`2.647/0.1245`，有效秩为6；最弱方向的
`k0_4`载荷为`0.99999`。`k0_4`在真值±0.05/0.10的条件切片loss均为0。
因此七参数点恢复门失败。下一切片只允许将`k0_4`固定为代码既有默认值
`5000 s^-1`（不得固定为合成真值），先验收目标电流最大绝对差`<=1e-8 A`
且truth objective `<=1e-6`；两门通过才运行六自由参数同预算恢复。该固定值
只作为条件输入，后续必须传播其范围，不能解释为估计值或材料常数。

执行结果：直接用开发求解精度`rtol=1e-6`检查原始电流时门失败，但收敛分析
证明该精度的数值漂移约`2.5e-7 A`，高于待验收差异。保持`1e-8 A`科学阈值
不变，改由独立`rtol=1e-8`计算验收后，默认值与真值的最大电流差为
`5.43e-9 A`、truth objective为`4.39e-13`，固定输入门通过；优化阶段仍保持
冻结`rtol=1e-6`。六参数256调用恢复仍失败：TPE最大/中位误差
`0.4076/0.2564`，TPE+Powell为`0.4041/0.2063`。因此停止优化器扩展，进入
其余自由参数的真正profile likelihood；不得以固定`k0_4`后维数减少为恢复
资格。

补参数重优化profile的开发结果进一步否决六个单参数点值：CN仅用于搜索具体
补偿候选，每个候选由LSODA原坐标确认。`k0_2/k0_3/G_OH/G_O/scaling`在
真值±0.10附近均存在`Δloss<1`解；`k0_1`只在低侧出现`Δloss>1`，高侧仍有
宽补偿区。由于“找到一个低loss候选”已经足以证明该profile位置的全局最小
不高于候选loss，本结论不依赖Powell是否声明收敛；但这些离散点仍不能解释为
置信区间。下一实现目标从“六参数点恢复”改为“可解释组合/单侧界 + 新协议
旋转敏感方向”，原协议不再追加优化器预算。

首轮组合提取不再直接使用真值点Jacobian，而是对LSODA确认的低-loss补偿位移
做train/selection分离SVD。最稳定候选为
`0.858*z(G_OH)-0.514*z(log10(k0_1))`；按当前开发边界等价于忽略常数后的
`G_OH-0.1132*log10(k0_1)` eV。冻结M0第一步正向BV项给出的局部尺度是
`RT ln(10)/((1-a)F)`；在`a=0.5`时它与旧写法`RT ln(10)/(aF)`数值同为
`0.1183 eV/dec`，当时无法区分。该接近只提示BV能垒—前因子补偿可能是物理
来源，仍必须压力测试：
改变schema边界、真值、频率/振幅及转移系数后，若物理单位系数不稳定，则只
能视为坐标伪影；只有组合profile闭合且留出协议稳定才允许升级为报告量。

执行压力测试否决了全局升级：该组合在`mixed_a`固定预算TPE+Powell下未找到
`Δloss<1`旁路，但迁移到`center`后偏移`-0.10/-0.05/+0.05`仍分别存在
`0.345/0.064/0.742`的LSODA候选。`center`重新拟合的最弱方向也转为

的收敛电流差`5.24e-7 A`未过门。故分区目前只是诊断事实，尚无可冻结规则。

V4.1推荐协议已进入联合恢复压力测试。加入`5 Hz/0.08 V`与`10 Hz/0.16 V`
匹配扫描后，`mixed_a`最大误差由约`0.404`降至`0.300`，但`center`仍为

但同时冻结“新增两协议不保证点可辨识”的边界；新实验到来前不再通过增加
优化器预算宣称进展。

2026-08-02在查看物理扰动结果前冻结下一项开发门。首先仅改变共享转移系数

网格不变；CN每点192次只搜索候选，LSODA原坐标确认。每个条件必须同时满足：
最弱方向仍由`G_OH/k0_1`主导且二者载荷平方和不低于`0.95`；selection最大
绝对运动不高于`0.02`；换算系数相对`RT ln(10)/(aF)`的偏差不高于`10%`；
系数随`a`严格单调下降并与`1/a`趋势一致；确认行有限且无ODE/特征失败。
任一条件失败即停止后续温度扰动，并把BV能垒—速率解释降级为特定条件下的
经验一致性。全部通过后才允许在固定`a=0.5`下预注册温度扰动；本门不改变
`center`已否决全局统一标度的结论。

依赖门实测后对实验作前置修订：`a=0.4`时默认与真值`k0_4`的`rtol=1e-8`
电流差为`7.00e-9 A`，通过既有`1e-8 A`门；`a=0.6`时为`1.78e-8 A`，失败。
因此禁止用默认`k0_4`继续比较两个`a`条件。为单独检验模型内部BV尺度，另建
乐观的合成机制隔离实验：在`a=0.4/0.5/0.6`三组中统一将`k0_4`固定为各自
合成真值，重新搜索和确认全部profile，不复用默认`k0_4`候选；其余门槛保持
不变。该实验只能验证方程内的条件尺度，不能授权真实反演固定或估计`k0_4`。

首次`a=0.4/0.5/0.6`结果揭示原预注册理论式写错了BV分支：冻结M0代码使用
`k_f=k0*exp[(1-a)F*eta/(RT)]`，而`G_OH`通过`E01`进入该正向过电位，故局部
补偿预测应为`RT ln(10)/((1-a)F)`，不是仅在`a=0.5`时数值相同的
`RT ln(10)/(aF)`。原假设按预注册口径记为失败，不能事后改式后把同一三组
数据称为独立验证。修正式在查看新结果前冻结，并使用未见holdout
`a=0.35/0.65`、`T=298.15 K`、baseline、`mixed_a`和truth-`k0_4`重验；
沿用载荷平方和`>=0.95`、selection运动`<=0.02`、系数相对修正理论偏差
`<=10%`及严格单调门。holdout失败则物理解读失败；通过也只获得“冻结M0内、
mixed_a局部的BV一致性”，不恢复全局标度或真实参数点估计资格。

holdout执行结果：`a=0.35`的经验/修正理论系数为
`0.07483/0.09101 eV/dec`，相对偏差`17.79%`，超过预注册`10%`门；
`a=0.65`为`0.15974/0.16903 eV/dec`，偏差`5.49%`。两者的
`G_OH/k0_1`载荷平方和及selection运动均通过，但整体门由`a=0.35`否决。
因此停止温度扰动：该组合只保留为有限参数区和协议范围内的经验补偿坐标，
不能称为跨转移系数BV标度。失败不影响此前“单参数点估计不成立”的结论。

为避免后续交接重新放大结论，已生成机器可读局部组合登记：它从6个源summary
和parameter schema独立重算系数、夹角与门结果，状态固定为`LOCAL_ONLY`。
登记确认跨协议局部几何通过、`center`跨锚点失败、转移系数机制门失败并禁止
温度扰动；同时禁止全局坐标、全局降维、单参数点值、BV定律和真实数据
可辨识声明。该登记不是参数空间分区器，不能用现有三个真值插值出适用边界。
证据位于`results/smoke/scaling_validation/dev-local-combination-registry-v1/summary.json`。

### 阶段E：计算和优化器

1. 先实施缓存、批量并行和评价复用；
2. 建立前向灵敏度/CVODES原型并与中心差分交叉验证；
3. 在冻结有效空间内先跑梯度多起点，再比较TPE、BIPOP-CMA-ES和TuRBO；
4. 单独开发新刚性后端并重过等价门；
5. 选择时同时报告调用数、墙钟时间、恢复和失败率。

### 阶段F：正式恢复与实验接续

在多真值、噪声、固定输入扰动和模型失配代理下重开A6。恢复实验后补齐元数据、
独立参数约束和留出协议，再决定是否允许真实数据联合反演。

### 阶段G：桌面端

只有计算接口、状态机、结果schema和允许展示的结论等级冻结后，才完整实施桌面
反演功能。本地与远程只是 Compute Provider，不改变科学契约。

## 14. 本方案完成定义

本方案不是以“压到某个预设维数”或“更换TPE”作为完成。完成需要：

1. 解析结构不辨识已消除并由等价测试覆盖；
2. 物理硬约束、软先验、有效参数和模型充分性诊断明确分层；
3. 有效维数由留出噪声门和组合恢复确定；
4. 被保留的变量具有可解释组合和稳定多协议响应；
5. 新优化器在固定预算下提高恢复而不增加失败；
6. 新后端通过独立物理、谐波和灵敏度等价门；
7. 固定输入、实验噪声、优化多盆地和模型失配得到分别报告；
8. 只有通过完整Gate的单参数或组合进入正式结果和桌面界面。
