# Gate A6 单参数 Objective Profile 设计

## 目的

五参数条件 TPE 恢复失败后，先判断失败来自目标地形还是优化搜索。第一阶段
只研究无噪声、其他参数取 synthetic truth 的单参数剖面，不估计统计置信区间。

## 方案比较

1. **确定性单参数网格（采用）**：逐参数扫描完整归一化边界，强制加入 truth
   点。成本可控，可直接看到平坦区、多极小值和失败区。
2. 二维参数网格：能显示非线性耦合，但五参数全部两两展开成本高；只在
   单参数通过后用于少数组合。
3. 继续增加 TPE trials：只能继续混合目标不可识别与优化器收敛问题，不能
   解释当前失败，暂不采用。

## 科学口径

- 参数：`k0_1,k0_2,k0_3,G_OH,G_O`。
- 真值：先使用 pilot 的困难真值 `mixed_b`。
- 模式：legacy、complex_snr、lockin_only、hybrid。
- 模拟：LSODA、8192 points、32 points/cycle、128 feature points。
- 目标：无噪声 synthetic target；其余参数固定为该 truth 的真实值。
- 网格：归一化边界上 41 个等距点，并额外强制包含 truth 坐标。
- 输出保留每个点的总损失、损失分量、ODE/Tafel 状态、运行时间和参数坐标。

## 摘要指标

每个模式和参数报告：

- truth 是否为有限全局最小值；
- 网格最小值与 truth 的归一化距离；
- truth 两侧最近有限点的离散局部曲率；
- `loss <= min + 1` 与 `loss <= min + 10` 的归一化宽度；
- 有限点比例、ODE 失败数和 Tafel 失败数；
- 是否存在与最小值接近但远离 truth 的离散极小区。

`min+1` 和 `min+10` 只是统一的目标地形诊断尺度，不解释为置信区间。
网格未解析出的窄极小值也不能据此宣称不存在。

## 门控

本阶段不自动冻结参数。只有满足以下条件的参数才进入两参数 profile：

1. truth 是有限全局最小值；
2. truth 两侧至少各有一个有限点；
3. 近最优区未跨越大部分参数边界；
4. 没有远离 truth 的近简并极小区。

若单参数 profile 已平坦或多解，该参数优先进入固定、窄先验或
diagnostic-only 候选。若单参数清晰但联合恢复失败，再用两参数 profile
定位非线性耦合。

## Provenance 与失败处理

正式脚本拒绝 dirty worktree 和已有非空输出目录。manifest 记录 commit、
命令、环境、truth、参数规格、网格、solver、模式及输出 SHA256。ODE 失败、
Tafel 失败和科学不可识别分别报告，不修改边界或阈值制造 PASS。
