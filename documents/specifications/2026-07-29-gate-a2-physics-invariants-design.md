# Gate A2 物理不变量与 M0 回退设计

## 1. 目标

Gate A2 验证当前五步碱性 OER M0 正演模型在正常参数范围内满足：

1. 五种表面覆盖度守恒且保持物理范围；
2. 反应速率与覆盖度导数遵守固定化学计量；
3. 外电路电流严格分解为电容与法拉第电流；
4. 热力学自由能闭合且单位口径一致；
5. 非法参数在求解前被拒绝；
6. 稳态求解失败不会伪装成合法初值；
7. 关闭 M1 后，完整 M0 输出不受 M1 参数影响；
8. 重构前后正常 M0 数值行为保持不变。

本 Gate 不增加反应步骤，不修改平衡电位来源，不评价实验拟合，也不证明
机理真实。

## 2. 当前证据与缺口

已有测试覆盖：

- 单状态覆盖度导数和为零；
- 一个短默认轨迹覆盖度位于 `[0,1]`；
- `ΣΔG=4.92 eV`；
- `beta_recon=0` 时 `effective_gamma` 为常数；
- 短 LSODA 正演可以运行。

缺口：

- RHS 把覆盖度归一化后计算速率，但边界处逐分量裁剪导数；裁剪可能破坏
  守恒；
- 五个基元速率没有独立接口，无法验证化学计量；
- 电流只以 `(E_app-phi_s)/Ru` 输出，没有保存电容与法拉第分量；
- `calculate_steady_state` 未检查 `sol.success`；
- 参数正值、有限值和 transfer coefficient 范围未集中验证；
- 只验证了 `effective_gamma`，未验证完整 RHS/轨迹的 M0 回退；
- 没有覆盖正式参数范围的轨迹库。

## 3. 固定反应与化学计量

基元速率顺序固定为：

```text
r_pre, r_1, r_2, r_3, r_4
```

覆盖度顺序固定为：

```text
theta_star, theta_ox, theta_OH, theta_O, theta_OOH
```

化学计量矩阵：

```text
        pre   1   2   3   4
star    -1   0   0   0   0
ox       1  -1   0   0   1
OH       0   1  -1   0   0
O        0   0   1  -1   0
OOH      0   0   0   1  -1
```

因此：

```text
dtheta/dt = S @ rates
ones.T @ S = 0
```

每列严格守恒一个表面位点。代码只能从该矩阵生成覆盖度导数，不再手写五条
相互独立表达式。

## 4. 速率接口

新增纯函数，输入 `t, y, params`，输出：

- 应用电位与五个过电位；
- 正向、反向速率常数；
- 五个净基元速率；
- 计算速率时实际使用的覆盖度；
- 原始覆盖度和与归一化因子。

该函数不修改输入，不计算 `dphi_s`，不做边界投影。

Gate 不采用“增加某个 `k0` 必须提高总电流”的伪单调门。多步覆盖度反馈下
总电流没有普遍单调性。只验证：

- 固定状态和电位下，每一步净速率对自身 `k0` 严格线性；
- 正向/反向速率常数比随对应过电位单调增加；
- 其他步骤的 `k0` 不改变该步瞬时速率。

## 5. 覆盖度归一化与边界投影

当前实现包含两个行为：

1. 若覆盖度和非零，先除以覆盖度和；
2. 若某覆盖度 `<=0` 且导数为负，把该分量导数设为零。

处理顺序：

1. 在重构前冻结当前实现的正常状态 RHS 与短轨迹基线；
2. 抽取速率和矩阵时先保留归一化与投影，证明行为基线不变；
3. 在正式参数库记录每次归一化偏差和投影触发次数；
4. 若正常轨迹投影触发次数为零，可在单独提交中删除投影，并重新验证；
5. 若任一正常轨迹触发投影，Gate A2 停止，不通过裁剪或调松阈值隐藏。

直接调用纯速率函数时，覆盖度必须有限、各分量 `>=-1e-12`，总和必须为正。
求解轨迹允许数值容差内的微小负值，但正式门仍检查全轨迹范围。

## 6. 电流与电荷恒等式

由当前表面电位方程：

```text
dphi_s/dt =
    (E_app - phi_s)/(Ru*Cdl*A)
    - gamma_eff*F/Cdl * sum(rates)
```

定义：

```text
i_solution   = (E_app - phi_s) / Ru
i_capacitive = Cdl * A * dphi_s/dt
i_faradaic   = gamma_eff * F * A * sum(rates)
```

必须满足：

```text
i_solution = i_capacitive + i_faradaic
```

新增 `current_components` 只使用同一组速率与 `dphi_s`，不得第二次以不同逻辑
计算反应。`solve_ode_system` 继续返回兼容的 `i_total=i_solution`；正式
审计另外保存三个分量和闭合残差。

## 7. 单位账本

冻结当前模型单位：

| 量 | 单位 |
|---|---|
| `E, phi_s, E0, dE` | V |
| `Ru` | ohm |
| `Cdl` | F cm⁻² |
| `A` | cm² |
| `gamma` | mol cm⁻² |
| `F` | C mol⁻¹ |
| `k0`、基元速率 | s⁻¹ |
| `theta` | 1 |
| `dphi_s/dt` | V s⁻¹ |
| 三个电流分量 | A |
| `G_*`、`DeltaG*` | eV per electron |
| `E01-E04` | V |

`G/e = E` 对单电子步骤成立；本模型每一步转移一个电子。代码不引入单位库，
但参数注册表和测试必须按该账本验证派生量。

## 8. 参数验证

求解前必须拒绝非有限值。范围：

- 严格正：`Ru,Cdl,A,gamma,F,R,T,f,total_time`；
- 非负：`k0_pre,k0_1,k0_2,k0_3,k0_4,dE`；
- `0 <= a <= 1`；
- `beta_recon >= 0`；
- 当 `beta_recon > 0` 时，`w_recon > 0`；
- `E_start,E_end,E0_pre,E01-E04,v` 必须有限；
- `t_span` 一维、有限、严格递增并位于 `[0,total_time]`。

`k0=0` 被允许，用于严格关闭单一步骤。负速率常数、负电容、零面积或
无效温度必须在调用 ODE 前失败。

## 9. 稳态求解

`calculate_steady_state` 必须：

- 检查 `sol.success`；
- 检查返回状态长度、有限值、覆盖度范围和守恒；
- 检查最终 RHS 范数是否低于冻结阈值；
- 失败时抛出带时间和 solver message 的异常。

不再默认回退到全 `theta_star` 初值。若调用者确需非稳态初值，必须显式设置
`use_steady_state=false`；不能把稳态失败与“用户选择不用稳态”混为一谈。

稳态 RHS 无穷范数冻结为 `<=1e-8`。当前默认参数的只读预检值为
`1.99e-16`；该值只用于确认阈值数量级，不构成正式结果。若当前 5 秒松弛
在任一正式案例不足，Gate 先 FAIL；不得在同次正式结果后增加松弛时间。

## 10. M0 回退

当 `beta_recon=0` 时：

- `E_recon` 和 `w_recon` 的任意有限值不得改变 `gamma_eff`；
- 基元速率、覆盖度 RHS、`dphi_s` 和三个电流分量必须逐点一致；
- 同一初值和 LSODA 配置下，完整轨迹必须在浮点容差内一致；
- 默认 optimizer 仍不得释放 M1 参数。

M1 已有正式比较结果保持被拒绝状态。Gate A2 只验证关闭扩展后严格恢复
M0，不重新评价 M1。

## 11. 行为基线

重构前以未改变物理代码的 commit `727ed64` 冻结：

- 12 个物理状态；
- 6 个时间点；
- 默认、低/高动力学、低/高电路和热力学边界参数；
- RHS、短 LSODA 轨迹、应用电位和总电流；
- 所有输入与输出 SHA-256。

基线只使用物理合法状态，禁止把非法覆盖度归一化行为当成科学基线。

重构后门：

- RHS 最大绝对差 `<=1e-12 × max(1,|baseline|)`；
- 总电流 NRMSE `<=1e-10`；
- 应用电位逐点相同；
- solver 成功状态一致。

若差异超过门，停止并定位；不更新基线覆盖新行为。

## 12. 正式参数库

正式审计使用固定的 12 个案例：

1. 默认参数；
2. 五个 `k0` 同时为默认值的 0.1 倍；
3. 五个 `k0` 同时为默认值的 10 倍；
4. `Ru=0.1 ohm`；
5. `Ru=500 ohm`；
6. `Cdl=5e-6 F cm^-2`；
7. `Cdl=80e-6 F cm^-2`；
8. `gamma=1e-10 mol cm^-2`；
9. `gamma=1e-7 mol cm^-2`；
10. `a=0.25`；
11. `a=0.75`；
12. `G_OH=1.8 eV, G_O=2.2 eV, scaling=3.6 eV`。

`Ru=0` 是当前 ODE/电流表达式的奇异点，不能作为合法参数。旧
`defaults.py` 的 `Ru_range=[0,200]` 必须与已经用于敏感性分析的正值域
`[0.1,500]` 统一；这只是当前模型的数值定义域，不解释为实验先验。若未来
需要理想零电阻极限，应另写解析分支，不能用极小正数冒充。

每例使用 LSODA、`first_step=1e-8`、至少 32 cycles、128 points/cycle。
本 Gate 只需 Mac；CN 不参与正式结论。

## 13. 正式阈值

- 覆盖度和最大误差 `<=1e-8`；
- 覆盖度最小值 `>=-1e-8`；
- 覆盖度最大值 `<=1+1e-8`；
- 边界投影触发次数必须为 0；
- 电流闭合：
  `max_abs_residual /
  max(max_abs_i_solution,max_abs_i_capacitive,max_abs_i_faradaic,1e-12)
  <=1e-10`；
- 所有状态、速率、电位和电流有限；
- 12/12 solver 和 steady-state 成功；
- steady-state RHS 无穷范数 `<=1e-8`；
- 热力学总和误差 `<=1e-12 eV`；
- M0 回退和行为基线满足第 10、11 节阈值。

任一案例失败，Gate A2 FAIL，不对失败案例单独放宽。

## 15. 失败分类

| 分类 | 条件 | 后续 |
|---|---|---|
| `FAIL_STRUCTURE` | 参数库、基线、文件或 provenance 不完整 | 停止 |
| `FAIL_NUMERICAL` | solver、有限值、守恒、电流闭合或基线失败 | 停止 |
| `FAIL_PHYSICS` | 化学计量、热力学、单位规则或 M0 回退失败 | 停止 |
| `PASS` | 所有结构、数值和物理门通过 | 关闭 Gate A2 |

失败后不修改机理、参数范围或阈值。需要改变协议时另建版本。

## 16. 压力测试

- 改动化学计量矩阵任一元素，守恒或基线测试必须失败；
- 删除任一电子步骤的法拉第贡献，电流闭合必须失败；
- 负 `Cdl/Ru/gamma/k0` 在 ODE 前失败；
- solver 返回 `success=false` 时稳态函数必须失败；
- 人为触发覆盖度投影时 Gate 必须记录并失败；
- `beta_recon=0` 下改变 `E_recon/w_recon` 不改变任何完整输出；
- 改写基线文件或参数库触发哈希失败；
- 只降低总损失不能影响 Gate A2。

## 17. 设计压力测试结论

- **机理漂移：** 固定五步反应和 E0 生成方式，不新增物理项。
- **数值掩盖：** 投影触发即失败，不用裁剪证明物理性。
- **抵消条件数：** 电容与法拉第电流可能很大但相互抵消；闭合残差以三个
  分量的最大绝对尺度归一化，不以抵消后的总电流单独归一化。
- **伪单调性：** 只验证瞬时基元速率定义，不规定耦合总电流方向。
- **回归风险：** 先冻结合法状态基线，再抽取内部结构。
- **单位过度工程：** 使用显式账本和量纲测试，不增加依赖。
- **失败退出：** steady-state、solver、守恒和电流闭合任一失败即停止。
- **A1 依赖：** A2 可使用合成参数独立完成；A1 `FAIL_METADATA` 仍禁止真实
  数据反演，A2 PASS 不能绕过。
