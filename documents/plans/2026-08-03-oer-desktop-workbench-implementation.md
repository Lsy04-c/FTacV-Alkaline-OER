## 2. 需求要点（v0.2 摘要）

- **桌面程序**：双击启动，macOS 优先，Tauri 2 主推。
- **工作台定位**：展示 + 任务编排；计算由自编代码外接（第一版接 Python），本地/远程可选。
- **统一接入语义**：提交 / 状态 / 取消 / 取回 / 校验；人 + AI 共用同一套契约。
- **Gate 失败仍出图**：正演不因 Gate 未通过而整单取消。
- **三个部分**：①样品与电极 → ②数据导入/自动识别/谐波质量 → ③正演/诊断反演/分阶质量/导出 md。
- **明确不做**：实验缺口推荐、强制 MATLAB、重写科学核心、SaaS/账号。

## 3. 差距清单（需求有 / 项目无）

1. 样品与电极登记页（Co₃O₄、基底、面积、参比、电解液、备注）
2. CV / LSV 导入类型（当前只有 FTacV 分析链路）
3. 谐波「建议最高阶」+ 严格度三档（严格/标准/宽松）
4. 每阶（含 DC）实验 vs 模型拟合质量可视化
5. Gate 失败仍出图（当前 simulate 行为待实测确认）
6. 导出稳定 Markdown 报告（样品、识别条件、任务口径、总目标、分通道质量、参数表、限制）
7. Tauri 2 桌面壳 + sidecar Python 后端
8. 接入契约文档化（供 AI 稳定调用）

## 6. 边界与风险

- **科学边界**：工作台只展示，不把诊断拟合升级为正式结论；Gate / 结论等级由计算侧给出。
- **Gate 失败出图**：若需改科学侧行为，须单独确认并记录；展示层「有结果就画」不改变 Gate 语义。
- **桌面壳顺序**：功能没补齐前套壳只是换皮，阶段 B 必须晚于阶段 A。
- **凭据安全**：SSH 密钥等不得打包进应用或写入结果文件。
