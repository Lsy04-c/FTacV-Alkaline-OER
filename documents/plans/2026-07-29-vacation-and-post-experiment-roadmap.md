# OER-FTAcV 休假期与恢复实验后路线

状态：当前唯一执行计划
更新日期：2026-07-29
总入口：`documents/project/PROJECT_SUMMARY.md`

## 1. 目标

休假期间充分使用现有四组 FTacV 数据，但只形成条件模型结论和实验设计；
恢复实验后补齐元数据与独立约束，重新验证参数可恢复性，最后才进入正式
真实数据联合反演。

## 2. 固定边界

- FT2、FT3、FT4、FT8 是不同实验，不是重复实验；
- 当前列序为电位、电流、时间；
- 当前单位按项目负责人声明为 `V vs RHE`、`A`、`s`；
- 仪器预处理仍为 `unresolved`；
- 正式后端为 LSODA/BDF，CN 仅作开发筛选；
- A6 当前为 `FAIL_RECOVERY`，自由参数和窄先验均为空；
- 休假期间禁止正式真实数据 TPE 和可信参数点估计；
- 不改变旧 Gate 的预算、阈值、边界或数据划分。

## 4. 休假期间

### V1：用户声明元数据补录

**输入**

- `data/raw/ftacv2-ref-5hz.txt`
- `data/raw/ftacv3-ref-5Hz.txt`
- `data/raw/ftacv4-ref-1hz.txt`
- `data/raw/ftacv8-ref-5Hz.txt`
- 项目负责人对列序、单位和 RHE 标尺的声明
- 配套 CHI CV 文件头

**行动**

1. 把 `potential_unit=V`、`potential_reference=RHE`、
   `current_unit=A`、`time_unit=s` 写为 `externally_declared`；
2. 来源说明明确项目负责人不是原实验执行者；
3. `instrument_preprocessing.value` 保持 `null`；
4. `instrument_preprocessing.source_kind` 保持 `unresolved`；
5. 重新运行 A1 runner 和独立 validator。

**输出**

- 更新的数据注册表；
- 新的不可覆盖 Gate A1 归档；
- 更新后的 A1 验收和项目状态。

**验收**

- 四个数据集列定义一致；
- 原始文件哈希不变；
- 结构和采样门仍通过；
- 元数据来源等级与声明一致；
- 预处理仍被明确列为缺口；
- 不因本次补录自动获得反演资格。

**停止条件**

- 声明与文件数值结构冲突；
- 任何原始文件哈希变化；
- validator 与 runner 对元数据状态不一致。

**禁止表述**

- “确认没有仪器预处理”；
- “Gate A1 已通过”，除非未来取得足够一手记录并重新验收；
- “数据单位由文件本身完整证明”。

### V2：条件模型可达性

**研究问题**

在冻结的 M0、目标契约、参数边界和当前元数据假设下，模型能否达到四组
实验的 DC/H1–H3 特征区域？

**输入**

- A2-R 正式物理实现；
- A4 稳定的实验特征；
- A5 通道契约和 128 点特征网格；
- Gate A6 参数角色；
- 四组实验分别生成的 target。

**设计**

1. 八个 `fixed` 参数保持登记值，并注册可解释的压力测试范围；
2. 五个 `diagnostic_only` 参数仅用于覆盖模型响应空间；
3. 使用预注册的低差异参数库，不用实验结果动态收窄边界；
4. 四组数据分别评价；
5. 先做小规模 LSODA smoke，再冻结正式条件分析预算；
6. 保存每个候选的参数、特征、失败原因和距离分量。

**输出**

- 每个数据集的模型可达包络；
- 实验特征到模型包络的距离；
- 可达/不可达的 DC、H1、H2、H3 分量；
- ODE、特征和边界失败区域；
- 固定参数扰动是否改变可达性结论。

**验收**

- 参数库和实验 target 在运行前冻结；
- 每个候选使用同一通道、权重、掩码和分母；
- 四组数据不合并；
- 正式分析使用 LSODA/BDF；
- 结果绑定 commit、配置、数据哈希和随机种子；
- 独立 validator 能重算可达性分类。

**停止条件**

- 目标通道随候选变化；
- ODE 失败率使覆盖无效；
- 参数库没有覆盖已注册边界；
- 计算预算超过预注册上限且尚未证明额外样本改变结论。

**禁止表述**

- 把最近候选称为真实参数；
- 把“模型可达”称为参数可识别；
- 把“模型不可达”直接称为新机理已证明。

### V3：DC/H1–H3 残差归因

**输入**

- V2 冻结候选和模型包络；
- 四组实验的 DC 与复数 H1–H3；
- `Cdl`、`Ru`、`E0_pre`、`gamma/A` 压力测试结果。

**行动**

- 按数据集、特征模式和电位区间分解残差；
- 分开幅值残差与包裹相位残差；
- 比较固定参数扰动、动力学参数扰动和热力学参数扰动方向；
- 标记多个原因可同时解释的残差，禁止强制单一归因。

**输出**

- DC/H1/H2/H3 残差矩阵；
- 电位分辨残差图；
- “模型项、背景项、元数据项、参数补偿、未解释”五类证据表；
- 每类判断的替代解释和未验证条件。

**验收**

- 所有残差使用实验减模拟的统一符号；
- 幅值和相位不混为一个无量纲总分；
- 至少保留一个反例或替代解释；
- FT4 不因 1 Hz 被排除；
- 结论不依赖单一最优候选。

**停止条件**

- V2 表明目标不可比较；
- 残差方向随合法特征变体翻转；
- 固定输入不确定度完全覆盖参数效应。

**禁止表述**

- 用单一残差图证明限速步骤；
- 把高阶谐波数值存在等同于实验可解析；
- 把四组数据差异解释为重复实验噪声。

### V4：实验信息设计

**输入**

- V2 可达性；
- V3 残差归因；
- 主要相关对：
  `k0_3–scaling_OOH_OH`、`gamma–A`、`G_OH–G_O`、
  `k0_2–k0_3–G_O`；
- 可用仪器和合理实验条件范围。

**行动**

1. 对候选频率、振幅、扫描速率和电位窗口计算有符号敏感性；
2. 比较敏感性列相关、最小奇异值和目标 profile 宽度；
3. 区分能由波形解除的耦合与必须独立测量的耦合；
4. 选择最小条件矩阵，不追求无目的全因子扩张；
5. 预注册每个新条件要区分的参数或模型解释。

**输出**

- 最小 FTacV 条件矩阵；
- EIS、面积、负载量和位点量独立测量清单；
- 每个条件的目标参数、预期信息增益和失败判据；
- 实验记录模板。

**验收**

- 每个新增条件对应一个明确耦合；
- 设计指标在 LSODA 下复核；
- 不使用现有实验拟合优度作为唯一设计标准；
- 包含元数据和预处理记录要求；
- 总实验量符合恢复实验后的时间和材料预算。

**停止条件**

- 条件变化不能降低任何主要相关；
- 模型预测的信息增益完全依赖未校准固定值；
- 所需实验超出设备能力。

**禁止表述**

- “更多数据一定提高可识别性”；
- 在获得结果后修改成功判据；
- 用同一批数据同时设计和宣称独立验证。

### V5：按需求解加速

**触发条件**

只有 V2/V3 的冻结预算证明 ODE 占主要 wall time，且现有并行和缓存不足时
才启动。

**优先级**

1. 8 workers、单 worker 单 BLAS 线程；
2. 复用不依赖候选的目标特征和配置；
3. 安全的 job 级断点续跑；
4. 评估编译型自适应刚性求解器；
5. 新后端重过 A3 特征空间等价性。

**输出与验收**

- 固定案例吞吐对比；
- 与 LSODA 的 DC/H1–H7 幅值和相位等价证据；
- 失败样本和回退策略；
- 只有 Gate 通过才可承担正式计算。

**停止条件**

- 加速改变正式特征；
- 调试成本超过本阶段总计算节省；
- V2/V3 不受 ODE wall time 主导。

## 5. 恢复实验后

### E1：一手元数据

保存仪器方法、原参比电极、RHE 换算、pH、温度、iR 补偿、滤波、平滑、
平均、背景扣除、裁剪、降采样、电流归一化和实验编号。

**验收：** 原始文件、方法文件和实验记录可一一对应；Gate A1 重跑通过后
才允许正式真实数据路线。

### E2：独立固定输入

独立测量或约束 `Ru`、`Cdl`、几何面积、负载量和有效位点量。无法独立
获得 `gamma` 时，预先定义允许报告的组合量。

**验收：** 中心、误差和来源可追溯；固定值扰动不会推翻候选自由参数结论。

### E3：结构化 FTacV 条件矩阵

按 V4 预注册矩阵采集多频率、多振幅、多扫描速率和必要电位窗口数据。

**验收：** 不遗漏失败实验；每个文件有独立 ID、原始字节哈希和完整元数据；
训练、设计和留出验证角色在反演前冻结。

### E4：敏感性与 profile 重建

在新条件上重算有符号敏感性、相关、单参数和二维 profile。

**验收：** 至少一个目标参数组合的相关下降且目标谷收窄；否则返回 V4 或
只报告组合量，不进入恢复。

### E5：A6-v2 合成恢复

使用多真值、实测噪声、多 seed、固定预算和 truth 隔离重新验证。

**验收：** 预注册误差、seed 离散、边界命中和求解成功门全部通过；失败时
停止 E6，不增加预算或改阈值覆盖失败。

### E6：正式真实数据联合反演

仅在 A1 和 A6-v2 均通过后启动。冻结共享参数、数据集特异参数、后端、
特征、预算和结果 schema。

**验收：** 多 seed 一致、留出条件可预测、固定输入误差进入结果；否则
降级为条件分析。

### E7：不确定度与机理验证

执行 bootstrap、固定输入误差传播、跨条件/批次复核和替代模型比较。

**验收：** 报告区间而非单点；区分实现事实、数值结论、数据支持判断和
机理假设。

## 6. 决策表

| 观察 | 判断 | 下一步 | 禁止 |
|---|---|---|---|
| M0 无法达到实验特征 | 模型或背景/元数据存在缺口 | V3 定位残差，必要时提出最小物理扩展 | 继续加优化预算 |
| M0 可达但参数集合宽 | 模型可用、参数不唯一 | V4 设计解除耦合实验 | 报告最近候选为真值 |
| 新数据降低相关并通过恢复 | 信息量增加 | E6 正式联合反演 | 跳过留出验证 |
| 新数据仍不能通过恢复 | 原始参数仍不具资格 | 固定、报告组合量或仅作诊断 | 事后放宽恢复门 |
| 只有 CN 给出改善 | 后端差异待解释 | LSODA/等价后端复核 | 直接升级科学结论 |

## 7. 当前完成判据

休假阶段完成需同时满足：

- V1–V4 形成可复现结果；
- 四组数据分别报告；
- 模型可达与参数可识别明确分开；
- 实验矩阵能对应主要参数耦合；
- 未启动正式真实数据 TPE；
- 结果、项目总览、纠错和 Git 状态同步。

恢复实验后阶段完成标准见 `documents/project/PROJECT_SUMMARY.md` 第 13 节。
