# Tafel 约束重建计划

## 结论

下一版计算只允许使用“独立数据已验收的表观 Tafel 约束”。当前 FTacV DC
包络中的 Tafel 数值降为诊断量；它不能单独充当稳态 OER Tafel，也不能再以
提取失败的固定罚分替代物理判断。

本计划不改变 2026-08-09 formal profile 的门或结论。该结果仍为
`FAIL_PROFILE_CONTRACT`，不得删点、改阈值或重写历史结果。

## 当前证据

- 原始数据含 3 条 CHI CV：`cv-ftacv2.txt`、`cv2-ftacv8.txt`、
  `cv4-ftacv3.txt`。头信息显示双扫描、0.1 V/s、0–0.7/0.9 V，记录了电流单位，
  但未记录 RHE 换算、iR 校正、面积定义、气泡/稳态判定和仪器预处理。
- 当前 `measure_tafel` 从电流阈值跨越计算 `ΔE/dec`。它会按电位去重并平均同一
  电位的正反扫数据，因此不适合直接处理存在滞后的 CV；它也不是稳态 Tafel 拟合。
- 当前 profile 的 `tafel_failed` 表示候选 DC 包络没有满足该提取器的固定窗口和
  电流阈值，随后以 `physical=100` 进入目标函数。它不是“模型违反 Tafel 机理”的
  独立证据。

## 约束来源与等级

| 来源 | 可承担的角色 | 不可承担的角色 |
|---|---|---|
| 已有 0.1 V/s CV | 预处理后形成 `exploratory_apparent_tafel`，用于选窗口和检查滞后 | 正式独立动力学约束 |
| 现有 FTacV DC 包络 | 信号诊断、与模型 DC 的一致性检查 | 稳态 Tafel、正式 hard gate |
| 新增慢速 LSV 或电位阶跃稳态数据 | 通过下列验收后形成 `validated_apparent_tafel` | 直接证明单一步反应机理或单个微观参数 |

即使通过验收，Tafel 仍是表观斜率；它受 iR、覆盖度、传质、表面重构与并行过程影响。

## 下一版本的实现边界

1. 新建独立 `TafelConstraint` 数据对象，记录原始文件 SHA-256、参比到 RHE 的换算、
   面积、iR 规则、所选扫描支、窗口、回归方法和不确定度。
2. CV/LSV 提取器必须保留单一扫描支，禁止按电位平均正反扫。用电流密度 `j`，而不是
   绝对电流，定义预注册的连续候选窗口。
3. 在多个连续窗口做稳健 `η`–`log10(j)` 回归；输出斜率、截距、R²、残差、窗口敏感性
   和正反扫差。算法只报告，不自行挑选“最好看”的窗口。
4. Tafel 不可提取时返回 `UNAVAILABLE` 与原因；物理可行域失败另用可解释的 hard
   predicate 表示。禁止以常数 100 同时充当“测量失败”和“物理不可能”。
5. 未产生 `validated_apparent_tafel` 前，formal feature contract 显式关闭 Tafel 通道；
   profile 和 CMA 不得因为该通道缺失而暗中加罚。

## `validated_apparent_tafel` 验收门

全部满足才允许进入下一版 formal 计算：

1. 原始数据、RHE 换算、iR 校正和面积来源可追溯；
2. 选定支在窗口内单调，背景/电容处理方法冻结；
3. 窗口跨至少一个 decade 的 `j`，并避开预氧化峰、气泡和明显传质平台；
4. 邻近窗口和合理预处理扰动下斜率稳定，且正反扫差被量化；
5. 至少两种低扫描速率或独立重复的结果在预注册容差内一致；
6. 模型与实验使用相同的 RHE、iR、面积和电流密度窗口；
7. 新增通道的合成恢复和 holdout 通过后，才允许它约束参数。

## 执行顺序

1. 为三条现有 CV 建立只读审计报告，明确缺失元数据和正反扫差；
2. 不把该报告接入反演，只确定新实验的电位/电流范围；
3. 补采慢速 LSV 或阶跃稳态数据，并完成上述验收；
4. 实现版本化提取器和 `UNAVAILABLE` 状态，先用合成数据测试；
5. 新建版本化 formal profile，随后才重新评估 CMA 资格。
