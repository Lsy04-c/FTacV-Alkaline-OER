## 1. 【阻断项】EIS 测 Ru —— 不做完不要做任何正式反演

**理由**：四组数据一致显示，Ru 从 5 改到 20 Ω 时 E⁰_eff 移动 154–349 mV、
k₀ 变 8–137 倍，而拟合质量几乎不变（ΔHarmPer 仅 0.016–0.071）。
**数据区分不出 Ru，但 Ru 决定反演出的机理参数**（§15）。

**技术**：A.C. Impedance（交流阻抗）

| 参数 | 设定 |
|---|---|
| 频率范围 | 100 kHz → 1 Hz |
| 每十倍频点数 | 10 |
| 交流振幅 | 5 mV（小振幅，保证线性） |
| 直流偏置 | **测两个**：① 开路电位 ② 1.55 V（拟合窗口中部，与 FTacV 同一参比） |
| Quiet Time | 2 s |

**读数**：Nyquist 图高频端与实轴的截距 = Ru。两个偏置下的值应接近；
若差异 > 20%，记录下来并告知。

**同时确认**：此前四组 FTacV 是否开了 iR 补偿。若开了，模型里的 `Ru`
含义完全不同，需要重新讨论。

**耗时**：约 10 分钟。

## 2. 空白基底 + 重复性（与第 1 组同日）

### 2.1 空白基底

同基底、同电解液、**同 FTacV 参数**，不涂催化剂，跑一次。
用途：背景通道，项目自己判定的欠拟合根因之一。

### 2.2 重复性

**同一个电极、不动电解池**，连续跑 3 次完全相同的 FTacV。
用途：目前谐波权重是从单次信号推的 SNR，而 roadmap §2.3 明确禁止把它
当实验不确定度。重复测量是唯一合法来源。

## 3. 【关键】降低负载 + 收紧电流量程

**这是收益最高、成本最低的一项。**

### 3.1 为什么

现有数据的噪声底 **8.7 µA**，与 ADC 量化噪声 `q/√12`（q = 3.0×10⁻⁵ A）
在一位有效数字内相等——**噪声底由仪器量程决定，不是随机噪声**（§14）。
后果是 H4–H7 信噪比只有 0.7–5.7。

**推断（请在仪器上核实）**：观测到的量化台阶 3.0×10⁻⁵ A 与
「16 位 ADC × Sensitivity 0.1 A/V」正好吻合（现有 CV 文件头显示
`Sensitivity (A/V) = 0.1`）。若成立，量化台阶随 Sensitivity 线性下降。

### 3.2 立刻可做的改进（零成本）

峰值电流约 11 mA。CHI 的 Sensitivity 满量程约为 10 V × 设定值：

| Sensitivity | 满量程 | 量化台阶 | 是否够用 |
|---|---|---|---|
| 0.1 A/V（现用） | ±1 A | 3×10⁻⁵ A | 浪费了 100 倍动态范围 |
| **1×10⁻² A/V** | ±100 mA | 3×10⁻⁶ A | **现有负载即可用，直接好 10 倍** |
| 1×10⁻³ A/V | ±10 mA | 3×10⁻⁷ A | 会超量程，需先降负载 |

**先做**：用现有电极、只把 Sensitivity 改为 1×10⁻² A/V 重跑一次，
对比 H4–H7 幅值。若量化台阶确实降到 3×10⁻⁶，这条推断即被证实。

### 3.3 负载梯度（同时服务于 `gamma` 的可辨识性）

Bonke 2016 能在 CoOx 上完成 OER 的 FTacV 反演，前提是
**Γ = 3–110 pmol/cm² 的超低负载**——催化直流电流足够小，谐波才被表面
氧化还原主导。本项目假定的 3×10⁻⁹ mol/cm² 高出 30–1000 倍，正处于
Bonke 刻意避开的区间。

而 profile likelihood 显示 `gamma` **只能给上限** ≲ 10⁻⁹·⁴（§26），
需要独立标定才能打破。

| 样品 | 目标负载 | 预期峰值电流 | 建议 Sensitivity |
|---|---|---|---|
| L1 | 现有负载 | ~11 mA | 1×10⁻² A/V |
| L2 | 现有 1/10 | ~1 mA | 1×10⁻³ A/V |
| L3 | 现有 1/100 | ~100 µA | 1×10⁻⁴ A/V |
| L4 | 现有 1/1000 | ~10 µA | 1×10⁻⁵ A/V |

- 负载用**沉积电量**或**称重**定量，必须记录
- 每个样品都做一次 CV（0–0.9 V 区间，扫速 100 mV/s）用于按
  `Γ = Q_ox /(F·A)` 独立估算位点密度——这是 Bonke 用的方法
- 若 L4 电流过小以致信噪比反而下降，记录下来即可，那本身是有用信息

## 4. 【关键】频率序列 —— 打破 `k0` 的上界不可辨识

**理由**：profile likelihood 显示 `k0` 的剖面从 10^1.5 一路平到 10^3.85
（2.35 decade），**只能给下限 ≳ 30 s⁻¹**（§26）。不同频率对不同速率
常数敏感，这是唯一的实验手段。

**同一个电极、同一天、除频率外全部参数相同。**

| f | 说明 |
|---|---:|
| 1 Hz | 与现有 ftacv4 可比 |
| 3 Hz | |
| 9 Hz | Bonke 2016 用的频率 |
| 27 Hz | ω ≈ 170 s⁻¹，覆盖 k₀ 下限以上 |

**执行前必须确认采样率上限**：谐波分析需要每个交流周期 ≥ 128 点
（现有数据是 256 点/周期）。

```
27 Hz × 128 点/周期 = 3.5 kHz
27 Hz × 256 点/周期 = 6.9 kHz
```

若仪器达不到，**按 `f_max = 采样率上限 / 128` 反推最高频率**，
不要为了上高频而牺牲每周期点数——那会直接毁掉高次谐波。

Bonke 试过 9 / 22 / 89 Hz，结论是 9 Hz 已足够、更高频无增益。
所以 27 Hz 是上界，不必再往上。

## 5. FTacV 通用参数（第 2–4 组共用）

| 参数 | 设定 | 依据 |
|---|---|---|
| 电位窗口 | **1.20 → 1.75 V**（与现有同一参比） | 实测 H3/H4 特征在 1.54 / 1.60 V，两侧留余量；避开更高电位的气泡与传质区 |
| 扫速 | **5 mV/s** | 比现有 3.9–19.5 mV/s 更慢更均一，同一特征上的交流周期数更多 |
| 交流振幅 ΔE | **主组 160 mV**，另做一组 **80 mV** 对照 | 160 mV 是现有值便于比较；80 mV 是 Bond 组标准，iR 畸变与法拉第整流更小 |
| 每周期采样点 | ≥ 256 | 现有数据一致，保证 H1–H7 远低于 Nyquist |
| Quiet Time | 2 s | |
| Sensitivity | 见第 3 节按电流选 | |
| iR 补偿 | **建议关闭**，让模型显式处理 Ru | 若必须开，务必记录补偿值 |

# 附:操作手册

> 菜单名以 CHI 常见界面为准(`Setup → Technique` / `Setup → Parameters` /
> `Control → Run Experiment`)。不同版本措辞略有差异,按实际界面对应即可。

## A. 每次开工前(约 20 分钟)

1. **配电解液**——1 M KOH,现配或确认未吸 CO₂(放久的 KOH 会碳酸化,
   影响 OER 起始电位)。记录批次与配制日期。
2. **电解池**——三电极:工作电极、Pt 丝对电极、参比电极。
   **把参比电极型号和内充液抄进记录表**,这是目前最缺的一项。
3. **除氧**——通 N₂ 或 Ar 15 分钟,之后保持液面上方吹扫(不要在液面下鼓泡,
   气泡会污染交流信号)。
4. **参比电极校准**(每批实验做一次即可)——用可逆氢电极或已知体系
   核对一次,记下换算关系。**没有这一步,所有电位值不能写进论文。**
5. 开工作站预热 15 分钟,`Control → Cell` 确认接线正确。

## B. 第 1 组:EIS 测 Ru

```
Setup → Technique → A.C. Impedance
Setup → Parameters:
    Init E             开路电位（先跑一次 Open Circuit Potential 读出来）
    High Frequency     100000 Hz
    Low Frequency      1 Hz
    Amplitude          0.005 V
    Quiet Time         2 s
Control → Run Experiment
```

跑完:

1. 看 **Nyquist 图**(Z' vs −Z''),高频端曲线与实轴的交点即 **Ru**。
   若软件有 `Data Processing → Impedance Fitting`,用 R(RC) 等效电路拟合读
   Rs 更准。
2. 把 `Init E` 改成 **1.55 V**(与 FTacV 同一参比),重复一次。
3. 两次的 Ru 应接近。**记下两个值**。

**同时确认**:`Control → iR Compensation` 之前是否被启用过。若启用,记下
补偿百分比——这直接影响模型里 `Ru` 的含义。

## C. 第 2 组:改量程重跑(验证量化推断)

用**现有那块电极**,FTacV 参数与之前完全一致,只改一处:

```
Setup → Parameters → Sensitivity:  0.1  →  0.01  (A/V)
```

跑完导出,把文件发我。我会核对量化台阶是否从 3.0×10⁻⁵ 降到 3.0×10⁻⁶。

**若跑到一半出现电流削顶(波形被切平)**,说明超量程,退回 0.1 并告诉我。

## D. 第 3 组:空白 + 重复性

1. **空白**:同一块基底,不涂催化剂(或用干净基底),FTacV 参数完全相同,
   跑一次。
2. **重复性**:换回催化剂电极,**不动电解池、不取出电极**,连续跑 3 次
   完全相同的 FTacV,中间只留 2 分钟静置。
   - 三次之间若差异明显,说明电极在演化(表面重构),这本身是重要信息,
     记下来。

## E. 第 4 组:负载梯度

以现有制备方法为基准,做 4 个样品:

| 样品 | 做法 | 预期电流 | Sensitivity |
|---|---|---|---|
| L1 | 现有条件 | ~11 mA | 0.01 |
| L2 | 沉积电量或涂布量 **1/10** | ~1 mA | 0.001 |
| L3 | **1/100** | ~100 µA | 1e-4 |
| L4 | **1/1000** | ~10 µA | 1e-5 |

每个样品按顺序做两件事:

1. **先做 CV**——用于按 `Γ = Q_ox/(F·A)` 估位点密度
   ```
   Setup → Technique → Cyclic Voltammetry
       Init E 0 V, High E 0.9 V, Low E 0 V, Scan Rate 0.1 V/s
       Segments 4（跑两圈，取第二圈）, Sensitivity 按电流选
   ```
2. **再做 FTacV**——参数见下方 F 节

**记录负载量**:沉积法记电量(库仑),涂布法记质量。这一项必填,
否则 L1–L4 只是"大中小",无法定量。

## F. 第 5 组:频率序列

**同一块电极**(建议用 L2 或 L3,信号与噪声平衡最好),同一天做完,
只改频率:

```
f = 1, 3, 9, 27 Hz
```

FTacV 通用参数:

```
电位窗口     1.20 → 1.75 V （与现有同一参比）
扫速         5 mV/s
交流振幅     0.16 V （主组）
采样         每个交流周期 ≥ 256 点
Quiet Time   2 s
iR 补偿      关闭
```

**做之前先确认采样率上限**:在参数对话框把频率设成 27 Hz,看软件允许的
最大采样率/最小采样间隔。

```
需要的采样率 = 频率 × 每周期点数
27 Hz × 256 = 6.9 kHz
27 Hz × 128 = 3.5 kHz  （最低可接受）
```

若仪器给不到 3.5 kHz,就**降低最高频率**,不要降每周期点数——
降点数会直接毁掉高次谐波。把实际能达到的采样率告诉我,我来定频率表。

做完后另加一组:同一电极、9 Hz、**振幅改 0.08 V**,作为 Bond 组标准值的对照。

## H. 常见问题

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 电流波形被切平 | 超 Sensitivity 量程 | 调大 Sensitivity 数值 |
| 高次谐波全是毛刺 | 量程过粗(量化)或有气泡 | 收紧 Sensitivity;检查液面吹扫 |
| 三次重复差异大 | 表面重构或电极脱落 | 记录下来,这是真实信息;检查电极附着 |
| Nyquist 高频端不闭合 | 接线电感或频率上限不够 | 检查接线;高频端取外推截距 |
| 起始电位漂移 | 参比电极老化或 KOH 碳酸化 | 校准参比;换新电解液 |
