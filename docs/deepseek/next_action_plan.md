# 下一步操作计划

项目：碱性 OER FTacV AEM 机理反演  
日期：2026-07-20  
当前状态：多组数据已完成数据质量分析、分阶段反演和 gamma 约束复核。热力学参数稳定性仍成立，但所有拟合等级仍为 `poor`。下一步目标不是中期汇报，而是定位模型缺项。

## 0. 当前结论边界

可以保留的判断：

- `scaling_OOH_OH` 和 `G_O` 跨数据稳定。
- `G_OH` 在 gamma 约束后 CV 从 0.26 降到 0.16，说明 gamma/A 耦合曾影响热力学参数。
- `gamma` 和 `k0_1~k0_4` 仍不可单独解释。
- 当前 AEM 热力学描述符有继续分析价值。

不能过度表述：

- 不能说完整 OER 机理已经证明。
- 不能说当前模型已能解释全部 FTacV 曲线。
- 不能用 `poor` 拟合结果支撑单步动力学结论。
- 不能继续靠扩大参数边界追求曲线贴合。

## 1. 第一阶段：复核 gamma 约束结果

目标：确认 gamma 固定后，热力学参数稳定性不是偶然结果。

操作：

1. 读取 `results/staged_inversion/staged_summary.md`。
2. 对比 gamma 自由和 gamma 固定两种结果。
3. 重点记录以下参数的 CV 变化：
   - `G_OH`
   - `G_O`
   - `scaling_OOH_OH`
   - `k0_1~k0_4`
4. 判断 gamma 固定是否只改善热力学参数，还是也改善动力学参数。

输出：

```text
results/staged_inversion/gamma_constraint_check.md
results/staged_inversion/gamma_constraint_check.csv
```

验收标准：

- 明确写出 gamma 固定前后每个参数的 CV。
- 明确说明哪些参数改善，哪些没有改善。
- 如果 `k0_i` 仍不稳定，继续禁止单独解释动力学速率常数。

停止条件：

- 如果热力学参数固定 gamma 后仍稳定，进入第二阶段。
- 如果热力学参数不稳定，回到目标函数和数据质量层重新检查。

## 2. 第二阶段：定位 poor fit 的来源

目标：判断 `poor` 拟合主要来自哪类模型缺项。

操作：

对每组 FTacV 数据分别检查：

1. DC 残差随电位的分布。
2. H1-H3 残差随电位的分布。
3. onset 附近是否系统偏差。
4. 高电流区是否系统偏差。
5. 低电位基线是否整体偏移。
6. H2/H3 的峰位是否和实验错位。

按残差形态归因：

| 现象 | 优先怀疑 |
|---|---|
| 低电位 DC 偏移 | 基底背景、Cdl、残余电流 |
| 高电流段偏差增大 | Ru、传质、气泡、膜层电阻 |
| onset 错位 | `E0_pre`、预氧化模型、活性相形成 |
| H2/H3 峰位错位 | 反应步骤电位响应或重构动力学缺项 |
| H4 以后噪声主导 | 不进入拟合，只保留诊断 |

输出：

```text
results/model_gap/model_gap_summary.md
results/model_gap/<dataset>_residual_diagnostics.png
```

验收标准：

- 每组数据至少给出一个主要偏差来源。
- 不允许只写“拟合不好”。
- 不允许用单一原因解释所有数据。

停止条件：

- 找到 1-2 个最可能模型缺项后，进入第三阶段。

## 3. 第三阶段：优先补背景模型，不先补复杂机理

目标：先排除宏观电极体系中最常见的非机理误差。

优先级：

1. 基线背景项。
2. 电容项改造。
3. Ru / 膜层电阻项。
4. 预氧化峰位置和宽度。
5. 传质或气泡影响。
6. 表面重构动力学。

建议先实现背景模型：

```text
I_total = I_AEM + I_cap + I_background
```

其中背景项先用最低复杂度：

```text
I_background(E) = b0 + b1 * E + b2 * E^2
```

要求：

- 背景项只能由低电位区或空白基底约束。
- 背景项不能自由吸收 OER 主反应区全部残差。
- 背景参数要单独输出，不能和 AEM 参数混为一谈。

输出：

```text
python/oer_aem/background.py
python/tests/test_background.py
results/model_gap/background_fit_check.md
```

验收标准：

- 加背景后，DC 低电位偏差应下降。
- `G_OH/G_O/scaling` 的跨数据 CV 不应明显变差。
- 如果背景项使热力学参数漂移，说明背景过拟合。

停止条件：

- 背景模型能改善 DC 但不破坏热力学稳定性，进入第四阶段。
- 背景模型不能改善，则不要继续加复杂背景，转查预氧化或传质。

## 4. 第四阶段：重跑分阶段反演

目标：在 gamma 约束和背景项加入后，检查 AEM 热力学描述符是否仍稳定。

固定或强约束：

```text
A = 1.0 cm2
gamma = 3e-9 mol/cm2 或实验估计范围
Cdl = 数据质量分析得到的范围
Ru = 先固定 10 ohm，后续由 EIS 更新
```

自由参数：

```text
G_OH
G_O
scaling_OOH_OH
必要时允许整体 k0_scale
```

暂不推荐自由放开：

```text
k0_1
k0_2
k0_3
k0_4
```

输出：

```text
results/staged_inversion/background_constrained_summary.md
results/staged_inversion/background_constrained_params.csv
```

判断标准：

- 如果 `G_O` 和 `scaling_OOH_OH` 仍稳定，说明热力学描述符抗背景干扰。
- 如果 `G_OH` 继续改善，说明 onset/背景耦合被削弱。
- 如果拟合仍是 `poor`，但残差结构更清楚，可以继续推进模型缺项。

停止条件：

- 形成“背景修正后热力学稳定性是否成立”的明确判断。

## 5. 第五阶段：决定下一轮模型缺项

目标：只选择一个缺项进入下一轮，不同时加入多个复杂机制。

候选方向：

| 方向 | 触发条件 |
|---|---|
| 预氧化动力学改造 | onset 和 H2/H3 峰位持续错位 |
| Ru/膜层电阻 | 高电流段偏差随电流增大 |
| 传质/气泡 | 高电位区 DC 和谐波同时异常 |
| 表面重构动力学 | 不同数据热力学稳定但曲线形状持续系统偏差 |
| 非 AEM/LOM 贡献 | AEM 热力学参数稳定但残差不能由背景、电阻、预氧化解释 |

本阶段不要直接引入 LOM。只有在背景、电阻、预氧化都排查后，才讨论 AEM 之外的机制。

输出：

```text
docs/model_gap_next_mechanism.md
```

内容必须包括：

- 选择哪个缺项；
- 为什么不是其它缺项；
- 需要哪些实验数据支持；
- 对代码需要改哪些文件；
- 加入后如何判断是否过拟合。

## 6. 实验侧需要补的数据

优先级从高到低：

1. 空白 Ti 板 FTacV。
2. Ti + 催化剂的重复 FTacV。
3. CV 预氧化峰积分，估算 gamma。
4. EIS，估算 Ru 和 Cdl。
5. 不同负载量样品，检查 gamma/背景是否随负载量变化。
6. 不同频率 FTacV，检查动力学时间尺度。

最低可行组合：

```text
空白 Ti FTacV + 当前四组 FTacV + CV 预氧化峰积分
```

有这三类数据后，才能更可靠地区分背景、电容、gamma 和 AEM 热力学参数。

## 7. 当前最推荐的执行顺序

按顺序执行，不跳步：

1. 生成 `gamma_constraint_check.md`。
2. 生成每组数据的 residual diagnostics。
3. 判断 `poor fit` 的主要残差类型。
4. 先实现最低复杂度背景项。
5. 在背景项约束下重跑 staged inversion。
6. 检查热力学参数 CV 是否保持稳定。
7. 决定下一轮只补一个模型缺项。

## 8. 给 DeepSeek 的硬性要求

- 每一步必须输出文件。
- 每一步必须写清楚判断标准。
- 不允许只给建议不生成结果。
- 不允许为了拟合放宽所有参数。
- 不允许单独解释 `k0_1~k0_4`。
- 不允许把 `poor fit` 包装成成果。
- 不允许同时加入多个复杂机制。

当前阶段的唯一目标：

> 找出当前 AEM 模型为什么 poor fit，同时验证热力学描述符稳定性是否能经受背景项和 gamma 约束的压力测试。
