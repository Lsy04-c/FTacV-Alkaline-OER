## B. 最高杠杆：降低负载 + 收紧电流量程

四组现有数据的噪声底由 ADC 量化台阶 `q = 3.0e-5 A` 决定
（`q/sqrt(12) = 8.7 µA`，与实测噪声底在一位有效数字内相等），
H4-H7 信噪比只有 0.7-5.7。

Bonke 2016 能在 CoOx 上完成水氧化 FTacV 反演的前提是
**Γ = 3-110 pmol/cm² 的超低负载**——催化直流电流足够小，谐波才被表面
氧化还原主导。本项目假定的 `gamma = 3e-9 mol/cm²` 高出 30-1000 倍，
峰值电流 11 mA，正处于 Bonke 刻意避开的区间。

两者是连锁的：

```
负载降 100x  ->  峰值电流 ~100 µA  ->  电流量程可加严 ~100x
             ->  量化台阶 ~3e-7 A   ->  H4-H7 SNR 从 1-5 变成 100-500
```

| # | 实验 | 说明 |
|---|---|---|
| B1 | **负载梯度**，4 个点跨 2 个数量级，向 pmol/cm² 量级靠 | 同时给出 Bonke 的 j-vs-Γ 曲线；并让 `gamma` 与 `A` 的简并可由外部信息打破 |
| B2 | **每个负载点收紧 CHI 电流量程** | 量化台阶随量程按比例下降。这是本清单中收益最高、成本最低的一条 |
| B3 | **一组 ΔE = 80 mV 对照**（现为 160 mV） | Bond 组标准值。160 mV 谐波更丰富但 iRu 畸变与法拉第整流也更强 |
| B4 | **保留一组完全按旧参数** | 保证与现有四组的可比性，避免整批数据断代 |
