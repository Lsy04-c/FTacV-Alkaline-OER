# Experimental Data Layout

本目录保存 OER-FTAcV 项目的实验数据。

## 目录

| 目录 | 用途 |
|---|---|
| `raw/` | 原始实验数据，不直接改动。 |
| `processed/` | 后续保存清洗、截取、背景扣除、谐波分析后的派生数据。 |

## 实验元数据（缺失项）

以下信息在数据采集时未记录，直接影响结果可解释性。补齐前相关结论不得
写入论文。见 `docs/项目纠错.md` 第 16 条。

| 项目 | 当前状态 | 影响 |
|---|---|---|
| **参比电极** | **未知** | 代码默认 `Eref = 0.0`，即假设电位列已是 V vs RHE。若不成立，所有热力学量（`G_OH`、`G_O`、低维模型的 `E0_eff`）整体平移一个未知常数 |
| 电解液及浓度 | 未知（推测 KOH） | `a_OH- ≈ 1` 假设的依据 |
| 催化剂与制备 | 未知 | 四组数据是否同一样品无法判断 |
| 负载量 | 未知 | `gamma` 只能靠文献猜值 |
| 电极真实面积 | 未知（代码取 `A = 1.0 cm²`） | 与 `gamma` 完全简并 |
| FT3 与 FT4 是否同一电极 | **待确认** | 决定 H3 峰位 +40 mV 位移能否作为频率色散使用 |

CV 文件（0–0.7 / 0.9 V）与 FTacV 文件（0.77–2.08 V）显然处于不同电位
参考系，二者之间没有记录换算关系。

## 采集条件（由数据实测，非记录值）

| 文件 | f | 交流幅值 | 扫速 | 直流窗口 | 仪器 |
|---|---:|---:|---:|---|---|
| `ftacv2-ref-5hz.txt` | 5.01 Hz | 160 mV | 9.7 mV/s | 1.124–1.623 | — |
| `ftacv3-ref-5Hz.txt` | 5.01 Hz | 160 mV | 19.5 mV/s | 0.925–1.922 | CHI660E |
| `ftacv4-ref-1hz.txt` | 1.00 Hz | 160 mV | 3.9 mV/s | 0.925–1.922 | — |
| `ftacv8-ref-5Hz.txt` | 5.01 Hz | 160 mV | 17.6 mV/s | 0.925–1.822 | CHI760F |

四组数据同时变化了窗口、扫速、频率与样品，任何跨组差异都无法单独归因。

**电流量化台阶均为 `3.0e-5 A`**，对应量化噪声 `q/sqrt(12) = 8.7 µA`，
与实测谐波间噪声底相等——噪声底由仪器量程而非随机噪声决定。
H4–H7 信噪比 0.7–5.7（详见 `docs/项目纠错.md` 第 14 条）。

## 使用原则

- `raw/` 内文件只读使用。
- 所有背景扣除、重采样、滤波结果保存到 `processed/`。
- 每个处理结果应记录来源文件、处理参数、时间和代码版本。
- 多组数据先用于判断信号质量、重复性和参数可识别性，再用于机器学习。
