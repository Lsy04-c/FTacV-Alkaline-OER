## 7. 追加修复：反演不可用 + 内置数据加载（2026-08-03 同日）

### 问题
用户反馈"只能正演不能反演"。根因：反演按钮被强前置条件挡住且静默——

```js
// 旧逻辑：必须上传数据 + Tafel 斜率提取成功，否则按钮 disabled 且无提示
disabled={invLoading||!(expAnalysis.calib&&expAnalysis.calib.tafel&&expAnalysis.calib.tafel.success)}
```

- 未上传实验数据 → `expAnalysis.calib` 为 undefined → 按钮灰掉
- 上传但 Tafel 提取失败（S1 已见 1804 次 tafel fail）→ 按钮灰掉
- 两者都不给用户任何提示，观感是"只能正演"

### 修复
1. **放宽 Tafel 前置**：后端 `inversion.py` 确认 `tafel=None` 时该通道自动
   `active=False / loss_weight=0`（无需改后端）。前端 guard 改为只需
   `expAnalysis`，Tafel 提取失败时传 `null` 并显示黄色提示
   "⚠ Tafel 提取失败：本次反演不含 Tafel 通道，仅用 DC+谐波"。
2. **内置数据加载**（满足"现有数据接前端"）：
   - 后端新增 `GET /api/data/samples`（列出 `data/raw` 下 4 组 FTacV）+ 
     `POST /api/data/analyze-by-file`（读文件→分析，含路径穿越防御）。
   - 前端上传区新增"或加载内置数据"下拉，一键加载 FT2/FT3/FT4/FT8。

### 验证
- 4 组内置数据 `analyze-by-file` 全部 success，f/dE 正确识别
  （FT2/3/8=5Hz，FT4=1Hz）
- 路径穿越 `../main.py` 被拒绝
- 前端 JSX 经 babel 编译通过；服务 7100 重启后 health/samples/页面均正常

## 9. 修复：谐波建议 / 实验图缺失 / 正演白屏（2026-08-03 同日）

三个反馈问题的根因与修复：

1. **谐波建议默认最高（错误）**
   - 根因：前端自算各阶 RMS 比值判断建议最高阶，但 `analyze` 返回的 `harmonics`
     是 65536 点原始幅值，且各阶量纲不一致，自算逻辑不可靠。
   - 修复：改用 `analyze` 已返回的 `harmonic_quality`（科学侧 `fit_harmonics` +
     每阶 `relative_rms`）。标准档直接用 `fit_harmonics`；严格/宽松按
     `relative_rms ≥ 3% / 0.3%` 调整。

2. **导入后无实验数据图像**
   - 根因：DataStep 只显示识别信息，未渲染实验曲线。
   - 修复：导入后立即显示「电流—电位」+「H1–H4 谐波包络」两图
     （用 `E_raw`/`i_raw`/`tdc`/`harmonics`，600 点降采样）。

3. **运行正演后整页空白**
   - 根因：`perHarmOpt` 渲染 14 条线 × 65536 点 ≈ 91 万点，ECharts 崩溃 → React 白屏。
   - 修复：新增 `downsample`/`downsampleXY`，所有实验/模型曲线降采样到 ≤800 点；
     实验曲线改用 `E_raw`/`i_raw`（原代码引用不存在的 `current` 字段）。

验证：JSX 编译通过；降采样后单图 ≤800 点，消除白屏源。

## 11. 修复：加载内置后整页空白（2026-08-03 同日）

- 根因：四步改为常驻挂载 + `display:none` 后，ResultsStep 挂载即 fetch 2D profile
  热图，ChartBox 在 `display:none` 容器里 `echarts.init` 拿不到尺寸 → 抛异常 →
  React 整树白屏。
- 修复两层：
  1. **惰性挂载**：App 用 `visited` 记录，首次进入某步才挂载组件（保证可见时
     初始化），之后 display 切换保留状态。避免未访问的步骤在隐藏态渲染图表。
  2. **ChartBox 尺寸保护**：容器 `offsetWidth/offsetHeight` 为 0 时延迟 init，
     由 ResizeObserver 检测到尺寸后再初始化并 setOption。
- 验证：JSX 编译通过；`visited` / `offsetWidth` / ResizeObserver 保护已就位。
