## 2. 新增后端 API（全部只读，不修改任何结果文件）

| 端点 | 返回内容 | 数据源 |
|------|----------|--------|
| `GET /api/results/overview` | 各结果模块是否可用 + 原始数据数量 | `results/` + `~/OER-FTAcV-archive/` |
| `GET /api/results/data-quality` | 四组 FTacV 数据质量摘要（f、dE、谐波 RMS、拟合通道） | `results/diagnostics/data_quality/data_quality_summary.csv` |
| `GET /api/results/profile2d?profile=<id>` | 12 个 2D 参数耦合 profile 摘要 + 指定 profile 的热图数据（≤40×40 降采样） | `~/OER-FTAcV-archive/results/1d6bf7a/a6_2d_profiles/20260728_064133/` |
| `GET /api/results/sensitivity` | A6 参数分类（可识别/耦合/固定 + 相关性） | `results/formal/architecture_validation/parameter_classification.csv` |
| `GET /api/results/recovery-s1` | A6-v2 S1 合成恢复验收结果（stage_status、eligible pairs） | `~/OER-FTAcV-archive/results/21284b5/.../summary.json` |

> 数据源说明：正式结果归档在 `~/OER-FTAcV-archive/results/`（Mac 归档），后端通过 `Path.home()` 定位，与 `wf sync` 的归档路径一致。

## 3. 新增前端标签页："项目结果"

在现有 `实验·正演·反演`、`MCMC` 之后新增第三个 tab。左侧面板展示：

- **实验数据质量**：四组 FTacV 的 f/dE/拟合通道
- **A6 参数分类**：每个参数的可识别性 + 最大相关性
- **A6-v2 S1 合成恢复**：stage_status、job/trials、ODE fail、eligible pairs

右侧面板展示：

- **2D 参数耦合热图**（ECharts heatmap，log₁₀ loss，可下拉切换 12 个 profile）
- **参数对耦合诊断表**：pearson_r、Δ1 width、耦合分类
